1. Base ortonormal adaptada. Si nos dan un plano con directores u, v: w = u × v es la normal; se normaliza u, w y se recalcula v = w × u (así v queda en el plano y perpendicular a u). Si nos dan una recta con director u (la figura es perpendicular a ella): u es la normal, v = (−u₂, u₁, 0) es perpendicular a u y w = u × v. Si nos dan un plano en implícitas, su normal son los coeficientes.
  2. Polígono regular de n lados, centro C y radio r en el plano de u, v: Pk = C + r(cos(2πk/n)·u + sin(2πk/n)·v), k = 0, …, n − 1. Como u y v son ortonormales, todos distan r de C y forman ángulos iguales.
  3. Estrella de n puntas: 2n vértices alternando dos radios r₁ (puntas) y r₂ (huecos) con ángulo π/n entre ellos.

Para dar volumen: piramide(base + [cúspide]) y prisma(base + tapa), donde la tapa es la base desplazada h·w. poligono(lista) dibuja la figura plana.

Las celdas usan regular(C, u, v, r, n) y estrella(C, u, v, r1, r2, n). Se definen solas al ejecutar la primera celda (junto con from geometria import *), pero aquí tienes su código para usarlas en tu SageMath:

 def regular(C, u, v, r, n, fase=0): return [C + r*(cos(2*pi*k/n + fase)*u + sin(2*pi*k/n + fase)*v) for k in range(n)] def estrella(C, u, v, r1, r2, n, fase=0): return [C + (r1 if k % 2 == 0 else r2)*(cos(pi*k/n + fase)*u + sin(pi*k/n + fase)*v) for k in range(2*n)] O = vector([0, 0, 0]); e1, e2 = vector([1, 0, 0]), vector([0, 1, 0]) poligono(regular(O, e1, e2, 1, 6)) + poligono(estrella(O + vector([3, 0, 0]), e1, e2, 1, 0.4, 5), color=azul)
