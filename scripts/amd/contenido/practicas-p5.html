Aₙ tiene 1 en la diagonal, −1 debajo y 1 en la última columna. Para n = 5, 10, …, 100: construye b para que la solución exacta sea (1, …, 1), resuelve con LU y con QR, calcula el error ‖x − xexacto‖ y compáralos. ¿Qué relación tiene con el factor de crecimiento 2ⁿ⁻¹?

Al escalonar, la última columna se duplica en cada paso (1, 2, 4, 8, …): el último pivote vale 2ⁿ⁻¹. Con n = 60 eso es ~10¹⁷, más de lo que distingue un número de coma flotante (unas 16 cifras), y la LU devuelve basura (error ≈ 17 en el cuaderno). La QR usa transformaciones ortogonales, que no agrandan los números, y mantiene errores de 10⁻¹⁴.

load('triangular.sage') def prueba(n): A = matrix(RDF, n, n) for i in range(n): A[i, i] = 1; A[i, n - 1] = 1 for j in range(i): A[i, j] = -1 x = vector(RDF, [1] * n); b = A * x P, L, U = A.LU() xlu = vector(resolucion_triangular(U, resolucion_triangular(L, P.transpose() * b, inferior=True)).list()) Q, R = A.QR() xqr = vector(resolucion_triangular(R, Q.transpose() * b).list()) return (xlu - x).norm(), (xqr - x).norm() for n in [5, 10, 20, 40, 50, 55, 60, 80, 100]: elu, eqr = prueba(n) print(f"n = {n:3}: error LU {elu:9.2e} error QR {eqr:9.2e} 2^(n-1) = {2.0^(n-1):.1e}")

Hasta n ≈ 50 las dos van bien; a partir de ahí el error de la LU se dispara, justo cuando 2ⁿ⁻¹ supera 10¹⁶. Conclusión: LU es más rápida, pero QR es más estable numéricamente.
