El cuaderno del examen de prácticas del subgrupo 2.4 sólo trae esta función, que resuelve M·x = b cuando M es triangular (superior o inferior, incluso no cuadrada) y se reutiliza con LU, QR y mínimos cuadrados. Sustitución hacia delante si es inferior (de la primera incógnita a la última) y hacia atrás si es superior; coste O(n²).

def resolucion_triangular(M, b, inferior=False): m, n = M.nrows(), M.ncols(); k = min(m, n) x = [0 for _ in range(n)] if inferior: # sustitución hacia delante for i in range(k): x[i] = (b[i] - sum(M[i, j]*x[j] for j in range(i))) / M[i, i] else: # sustitución hacia atrás for i in range(k - 1, -1, -1): x[i] = (b[i] - sum(M[i, j]*x[j] for j in range(i + 1, n))) / M[i, i] return matrix(n, 1, x) # columna n × 1 print(resolucion_triangular(matrix(QQ, [[2, 1], [0, 3]]), [5, 6]).T)
