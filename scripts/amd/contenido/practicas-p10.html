• Giro de ángulo α alrededor de la recta ⟨k⟩ (k unitario): se completa k a una base ortonormal positiva B = [a b k] (a × b = k) y G = B·Rz(α)·Bᵗ, con Rz(α) = cos α, −sin α, 0; sin α, cos α, 0; 0, 0, 1. Sin construir la base: G = cos α·I + sin α·[k]× + (1 − cos α)·kkᵗ (fórmula de Rodrigues).
  • Proyección oblicua sobre el plano n·x = 0 en la dirección d (con n·d ≠ 0): p(x) = x − n·x|n·dd, es decir, P = I − d nᵗ|nᵗd. Si d es la normal es la proyección ortogonal.
  • Diagonalizar: A es diagonalizable si tiene n vectores propios independientes (si los autovalores son distintos, siempre). Entonces A = P·D·P⁻¹ y Aᵏ = P·Dᵏ·P⁻¹, y Dᵏ sólo eleva la diagonal.
  • Colocar un objeto: si sus coordenadas están dadas respecto de la base canónica, en la base B = [a b c] con origen C los vértices pasan a C + B·v. Para mover sin deformar, B ortonormal.
