Tema 1

1.1La lógica como cálculo (reglas de formación y transformación)

Usa el cálculo de juguete de clase. Primitivos: A, A′, A″, …; B, B′, B″, … y la operación X. Reglas de formación: RF1 una A con cualquier nº de apóstrofes es ebf; RF2 ídem con B; RF3 ebf de A, seguida de X, seguida de ebf de B, es ebf; RF4 ebf de B, X, ebf de A, es ebf. Reglas de transformación: RT1 AⁿXBᵐ ⇒ BᵐXAⁿ; RT2 BⁿXAᵐ ⇒ AᵐXBⁿ; RT3 AⁿXBᵐ ⇒ AⁿXBᵏ (cambia los apóstrofes de la B); RT4 BⁿXAᵐ ⇒ BⁿXAᵏ (cambia los apóstrofes de la A).

Ejercicio 1.1.1Ver solución →

Indica cuáles de estas expresiones son ebf y con qué regla:

  1. A″
  2. A′ X B″

  5. X B′
  6. B′ X
Ejercicio 1.1.2Ver solución →

Ejercicio 1.1.3Ver solución →

Ejercicio 1.1.4Ver solución →

  3. ξ(p, r, ¬q) = ∅: satisfacible, con modelo ν(p) = V, ν(r) = V, ν(q) = F (s cualquiera).
  4. ξ(p, ¬r) = {□; {q, s}}: {r} pierde su único literal. Contiene □: no hay modelo con p = V y r = F.
  5. ξ(¬p) = {{q}; {¬q, ¬r}; {q, r, s}}; ξ(¬p, q) = {{¬r}}; ξ(¬p, q, ¬r) = ∅. Modelo: ν(p) = F, ν(q) = V, ν(r) = F.
Solución 4.3.2← Enunciado

Con ν(p) = F, ν(q) = F, ν(r) = V, ν(s) = V: ξ es F (falla {p, q}) pero ξ(p) es V. Tienen valores distintos, luego ξ ≢ ξ(p). Pero cualquier modelo de ξ(p), ampliado con ν(p) = V, es modelo de ξ: se conserva la satisfacibilidad.

4.4DPLL

Solución 4.4.1← Enunciado

Sin tautologías, unitarias, puros (p y q aparecen con los dos signos) ni subsumidas. Ramificación por p:

  • Rama p: ξ(p) = {{q}; {¬q}} → unitaria q → {□}. Backtracking.
  • Rama ¬p: ξ(¬p) = {{q}; {¬q}} → unitaria q → {□}.

Las dos ramas de la primera ramificación acaban en □: INSATISFACIBLE.

Solución 4.4.2← Enunciado

Sin tautologías, unitarias, puros ni subsumidas. Ramificación por p:

  • Rama p: ξ(p) = {{q, ¬r}; {r}; {¬q, ¬r}} → unitaria r: {{q}; {¬q}} → unitaria q → {□}. Backtracking.
  • Rama ¬p: ξ(¬p) = {{¬q}; {q, ¬r}; {q, r}} → unitaria ¬q: {{¬r}; {r}} → unitaria ¬r → {□}.

INSATISFACIBLE. Interpretación: las tres primeras cláusulas dicen q → p, r → q y p → r (las tres tienen el mismo valor); la cuarta exige alguna V y la quinta alguna F.

Solución 4.4.3← Enunciado
  1. Tautología: se elimina {p, ¬p, r}. Queda {{q, r}; {q, r, ¬s}; {¬q, s}; {¬r, ¬s}; {s, t}}.
  2. No hay unitarias.
  3. Literal puro t (no aparece ¬t): ξ(t) = {{q, r}; {q, r, ¬s}; {¬q, s}; {¬r, ¬s}}.
  4. Inclusión: {q, r} ⊆ {q, r, ¬s}, se elimina {q, r, ¬s}. Queda {{q, r}; {¬q, s}; {¬r, ¬s}}.
  5. Sin unitarias ni puros: ramificación por q. ξ(t, q) = {{s}; {¬r, ¬s}} → unitaria s: {{¬r}} → unitaria ¬r: ∅.

SATISFACIBLE, modelo ν(t) = V, ν(q) = V, ν(s) = V, ν(r) = F (p cualquiera). Comprobación en las originales: {p, ¬p, r} V; {q, r} V por q; {q, r, ¬s} V por q; {¬q, s} V por s; {¬r, ¬s} V por ¬r; {s, t} V. Correcto.

Solución 4.4.4← Enunciado

Sin tautologías, unitarias, puros ni subsumidas. Ramificación por p:

  • Rama p: ξ(p) = {{r}; {¬r}; {q, s}; {¬q, ¬s}} → unitaria r → {□; {q, s}; {¬q, ¬s}}. Rama fallida, backtracking.
  • Rama ¬p: ξ(¬p) = {{q}; {q, s}; {¬q, ¬s}} → unitaria q: {{¬s}} → unitaria ¬s: ∅.

4.6Árboles semánticos

Solución 4.6.1← Enunciado

Se lee ((p → q) ∧ (q → p)) → (p ↔ q).

  • Rama p (p := V): ((V → q) ∧ (q → V)) → (V ↔ q) ≡ (q ∧ V) → q ≡ q → q ≡ V. ÉXITO.
  • Rama ¬p (p := F): ((F → q) ∧ (q → F)) → (F ↔ q) ≡ (V ∧ ¬q) → ¬q ≡ ¬q → ¬q ≡ V. ÉXITO.

Todas las hojas son ÉXITO: TAUTOLOGÍA.

Solución 4.6.2← Enunciado
  • Rama p: (V ∨ q) ∧ (V → ¬q) ∧ (q → r) ≡ ¬q ∧ (q → r).
    • Rama q: ¬V ∧ … ≡ F. FALLO.
    • Rama ¬q: V ∧ (F → r) ≡ V. ÉXITO (p = V, q = F, r cualquiera).
  • Rama ¬p: (F ∨ q) ∧ (F → ¬q) ∧ (q → r) ≡ q ∧ (q → r).
    • Rama q: V ∧ (V → r) ≡ r.
      • Rama r: V. ÉXITO (p = F, q = V, r = V).
      • Rama ¬r: F. FALLO.
    • Rama ¬q: F. FALLO.

Hay ÉXITO y FALLO: satisfacible y falseable (contingente). Modelos (p, q, r): (V, F, V), (V, F, F) y (F, V, V).

Solución 4.6.3← Enunciado
  • Rama p: (V → q) ∧ (q → r) ∧ V ∧ ¬r ≡ q ∧ (q → r) ∧ ¬r.
    • Rama q: (V → r) ∧ ¬r ≡ r ∧ ¬r ≡ F. FALLO.
    • Rama ¬q: F. FALLO.
  • Rama ¬p: … ∧ F ∧ … ≡ F. FALLO.

Todas FALLO: INSATISFACIBLE (contradicción).

4.7Tableaux semánticos

Solución 4.7.1← Enunciado

      • β q → r, rama r: {q, ¬p, r} ✓

Solución 4.7.2← Enunciado

      • β q → r, rama r: {r, ¬r, …} ×

Todas las hojas cerradas: ¬Φ insatisfacible, luego Φ es tautología.

4.8Integradores

Solución 4.8.1← Enunciado
  1. FNC: (¬p ∨ q) ∧ (¬q ∨ r) ∧ (¬r ∨ ¬p) ∧ (p ∨ q) (interdefinición en las tres implicaciones). Forma clausal {{¬p, q}; {¬q, r}; {¬r, ¬p}; {p, q}}.
  2. DPLL: sin tautologías, unitarias, puros ni subsumidas. Ramificación por p.
    • Rama p: ξ(p) = {{q}; {¬q, r}; {¬r}} → unitaria q: {{r}; {¬r}} → unitaria r → □. Backtracking.
    • Rama ¬p: ξ(¬p) = {{¬q, r}; {q}} → unitaria q: {{r}} → unitaria r: ∅. SATISFACIBLE, modelo ν(p) = F, ν(q) = V, ν(r) = V.
  3. Árbol semántico:
    • Rama p: (V → q) ∧ (q → r) ∧ (r → F) ∧ V ≡ q ∧ (q → r) ∧ ¬r. Rama q: r ∧ ¬r ≡ F, FALLO. Rama ¬q: F, FALLO.
    • Rama ¬p: (F → q) ∧ (q → r) ∧ (r → V) ∧ (F ∨ q) ≡ (q → r) ∧ q. Rama q: r; rama r ÉXITO, rama ¬r FALLO. Rama ¬q: F, FALLO.
    • Un único ÉXITO: p = F, q = V, r = V. Satisfacible, no tautología.
  4. Tableau: dos α → {p → q, q → r, r → ¬p, p ∨ q}. β p ∨ q:
    • Rama p: β r → ¬p da ¬p (×) o ¬r; con ¬r, β q → r da r (×) o ¬q; con ¬q, β p → q da ¬p (×) o q (×). Rama p cerrada.
    • Rama q: β q → r da ¬q (×) o r; con r, β r → ¬p da ¬r (×) o ¬p; con {q, r, ¬p}, β p → q da ¬p ✓ o q ✓. Hojas abiertas {q, r, ¬p}.
  5. Las tres técnicas dan el mismo y único modelo: ν(p) = F, ν(q) = V, ν(r) = V.
Solución 4.8.2← Enunciado

Formalización: {a → b, b → ¬c, c ∨ a} ⊨ ¬c → b. Cláusulas: {¬a, b}, {¬b, ¬c}, {c, a}. Conclusión negada: ¬(¬c → b) ≡ ¬c ∧ ¬b, CS = {{¬c}; {¬b}}.

  • Resolución con CS: 1. {¬a, b}; 2. {¬b, ¬c}; 3. {c, a}; 4. {¬c} CS; 5. {¬b} CS; 6. {a} R_c(3, 4) CS, Subsumida(3); 7. {¬a} R_b(1, 5) CS, Subsumida(1); 8. □ Rₐ(6, 7) CS.
  • DPLL: unitaria ¬c → {{¬a, b}; {a}; {¬b}}; unitaria a → {{b}; {¬b}}; unitaria b → □. Sin ramificar: insatisfacible.
  • Árbol semántico sobre (¬a ∨ b) ∧ (¬b ∨ ¬c) ∧ (c ∨ a) ∧ ¬c ∧ ¬b: rama c FALLO (por ¬c). Rama ¬c: (¬a ∨ b) ∧ a ∧ ¬b; rama a: b ∧ ¬b ≡ F, FALLO; rama ¬a: F, FALLO. Todas FALLO.
  • Tableau: raíz {a → b, b → ¬c, c ∨ a, ¬(¬c → b)}; α → ¬c, ¬b. β c ∨ a: rama c × (con ¬c); rama a: β a → b, ¬a × (con a), b × (con ¬b). Cerrado (no hace falta descomponer b → ¬c).

Las cuatro técnicas coinciden: VÁLIDO.

Solución 4.8.3← Enunciado
