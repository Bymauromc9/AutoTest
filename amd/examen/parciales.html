        S1 · aplicación lineal · 1 p

        f: ℝ³ → ℝ³, f(x, y, z) = (x + y, y − z, x + z). a) Matriz en la base canónica. b) Base y dimensión del núcleo y de la imagen; implícitas de la imagen. c) ¿Es inyectiva? ¿Sobreyectiva? d) Matriz de f en la base B = {(1, 1, 0), (0, 1, 1), (1, 0, 1)}.

        Resolución explicada

        a) Por columnas, las imágenes de e₁, e₂, e₃: A = 11001−1101; det A = 0.

        b) Núcleo: x + y = 0, y − z = 0 (la tercera ecuación es la suma de las dos) ⇒ Ker f = ⟨(1, −1, −1)⟩, dim 1. Imagen: dim 3 − 1 = 2, generada por las columnas independientes (1, 0, 1) y (1, 1, 0); su normal es (1, 0, 1) × (1, 1, 0) = (−1, 1, 1).

        ResultadoKer f = ⟨(1, −1, −1)⟩; Im f = ⟨(1, 0, 1), (1, 1, 0)⟩ = {−x + y + z = 0}

        c) Ni inyectiva (núcleo no nulo) ni sobreyectiva (imagen de dimensión 2 < 3).

        d) MB = P⁻¹AP con P = [b₁ b₂ b₃] por columnas. Directamente: f(b₁) = (2, 1, 1) = b₁ + b₃, f(b₂) = (1, 0, 1) = b₃, f(b₃) = (1, −1, 2) = −b₁ + 2b₃:

        ResultadoMB = 10−1000112

        S4 · aritmética modular · 1 p

        a) Inverso de 17 módulo 43 con el algoritmo de Euclides extendido. b) Resuelve 17x ≡ 5 (mod 43). c) Calcula φ(360) y, con el teorema de Euler, 7⁹⁸ mod 360. d) Calcula 3¹⁰⁰ mod 7.

        Resolución explicada

        a) 43 = 2·17 + 9; 17 = 1·9 + 8; 9 = 1·8 + 1. Hacia atrás: 1 = 9 − 8 = 9 − (17 − 9) = 2·9 − 17 = 2(43 − 2·17) − 17 = 2·43 − 5·17. Luego 17⁻¹ ≡ −5 ≡ 38.

        b) x ≡ 38·5 = 190 ≡ 18 (mod 43). Comprobación: 17·18 = 306 = 7·43 + 5 ✓.

        c) 360 = 2³·3²·5, así que φ(360) = 360·(1 − ½)(1 − ⅓)(1 − ⅕) = 96. Como mcd(7, 360) = 1, Euler da 7⁹⁶ ≡ 1 (mod 360) y 7⁹⁸ = 7⁹⁶·7² ≡ 49.

        d) Pequeño teorema de Fermat: 3⁶ ≡ 1 (mod 7) y 100 = 6·16 + 4, así que 3¹⁰⁰ ≡ 3⁴ = 81 ≡ 4.

        Resultadoa) 38; b) x ≡ 18 (mod 43); c) φ(360) = 96 y 7⁹⁸ ≡ 49 (mod 360); d) 4

        4.0La función que hay que llevar preparada

        El cuaderno del examen de prácticas del subgrupo 2.4 sólo trae esta función, que resuelve M·x = b cuando M es triangular (superior o inferior, incluso no cuadrada) y se reutiliza con LU, QR y mínimos cuadrados. Sustitución hacia delante si es inferior (de la primera incógnita a la última) y hacia atrás si es superior; coste O(n²).

        resolucion_triangular

        def resolucion_triangular(M, b, inferior=False):
    m, n = M.nrows(), M.ncols(); k = min(m, n)
    x = [0 for _ in range(n)]
    if inferior:                                   # sustitución hacia delante
        for i in range(k):
            x[i] = (b[i] - sum(M[i, j]*x[j] for j in range(i))) / M[i, i]
    else:                                          # sustitución hacia atrás
        for i in range(k - 1, -1, -1):
            x[i] = (b[i] - sum(M[i, j]*x[j] for j in range(i + 1, n))) / M[i, i]
    return matrix(n, 1, x)                         # columna n × 1
print(resolucion_triangular(matrix(QQ, [[2, 1], [0, 3]]), [5, 6]).T)

        P3 · proyección y distancia

        W = ⟨(1, 1, 0, 1), (1, 0, 1, 1)⟩ y v = (1, 2, 3, 4). Base ortogonal de W, proyección de v sobre W y distancia de v a W.

        Resolución explicada

        Gram-Schmidt: w₁ = (1, 1, 0, 1), w₂ = (1, 0, 1, 1) − ⅔(1, 1, 0, 1) = (1/3, −2/3, 1, 1/3). proy = v·w₁w₁·w₁w₁ + v·w₂w₂·w₂w₂ = 7/3·w₁ + 2·w₂.

        ResultadoproyWv = (3, 1, 2, 3); v − proy = (−2, 1, 1, 1); d(v, W) = √7

        Prácticas P3

        A = matrix(QQ, [[1, 1, 0, 1], [1, 0, 1, 1]]); v = vector(QQ, [1, 2, 3, 4])
G, M = A.gram_schmidt(); p = sum((v*g)/(g*g)*g for g in G.rows())
print(G, p, v - p, (v - p).norm(), A*(v - p))
        P4 · figura en 3D

        Dibuja un prisma pentagonal de altura 2 con la base centrada en (1, 1, 1), radio 1 y perpendicular a la recta de dirección (1, 2, 2).

        Resolución explicada

        Base adaptada: w = (1, 2, 2)/3 (normal), u = (−2, 1, 0)/√5, v = w × u. Vértices C + cos(2πk/5)u + sin(2πk/5)v; la tapa es la base + 2w.

        Prácticas P4

        from geometria import *
C = vector([1, 1, 1]); w = vector([1, 2, 2]).normalized(); u = vector([-w[1], w[0], 0]).normalized(); v = w.cross_product(u)
base = [C + cos(2*pi*k/5)*u + sin(2*pi*k/5)*v for k in range(5)]
recta(w, C=C) + prisma(base + [P + 2*w for P in base], wire=True)
