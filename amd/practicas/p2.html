              Filas, columnas y propiedades de una matriz en SageMath.

              0.1Lo que hay que saber escribir

              • M.row(i) / M.column(j): fila o columna como vector. M[i, :] / M[:, j]: fila o columna como matriz (1 × n o n × 1). La diferencia importa al multiplicar: vector × vector es el producto escalar (un número), columna × fila es una matriz.
              • A.solve_right(b): resuelve A·x = b (mucho más rápido que rref para sistemas grandes).
              • %time orden: mide el tiempo que tarda la orden.
              • M.dimensions(), M.rank(), M.is_diagonal(), M.is_triangular("upper") / ("lower"), M.is_unitary() (¿ortogonal?).

              La función resolucion_triangular(M, b, inferior=False) del enunciado (se da en el examen si hace falta) resuelve un sistema triangular por sustitución: hacia atrás si M es triangular superior y hacia delante si es inferior. Hace n²/2 operaciones, frente a las ~n³/3 de Gauss.

              resolucion_triangular (ejecútala antes de los ejercicios 4 y 6)

              def resolucion_triangular(M, b, inferior=False):
    """Resuelve M x = b con M triangular (superior por defecto). Coste O(n^2)."""
    n = M.nrows()
    x = [0 for i in range(n)]
    if inferior:          # sustitución hacia delante: de la primera fila a la última
        for i in range(n):
            suma = sum(M[i, j] * x[j] for j in range(i))
            x[i] = (b[i] - suma) / M[i, i]
    else:                 # sustitución hacia atrás: de la última fila a la primera
        for i in range(n - 1, -1, -1):
            suma = sum(M[i, j] * x[j] for j in range(i + 1, n))
            x[i] = (b[i] - suma) / M[i, i]
    return matrix([a for a in x])   # con b columna (n × 1) devuelve una columna

              Ejemplo a mano (sustitución hacia delante)

              2001304−21x = 478: 2x₁ = 4 ⇒ x₁ = 2; 2 + 3x₂ = 7 ⇒ x₂ = 5/3; 4·2 − 2·5/3 + x₃ = 8 ⇒ x₃ = 10/3. Solución (2, 5/3, 10/3). (El cuaderno oficial da x₃ = 2/3 por una errata: 8 − 10/3 + x₃ = 8 da x₃ = 10/3.)

              Ejercicio 1

              Ejercicio 1 · Interpretaciones del producto

              El fichero ejercicio1.sobj trae dos matrices 3 × 3, A y B; sea C = A·B.

              Ejercicio 1 (a, b) · C₁₁ y filas por columnas

              a) Calcula C₁₁. b) Calcula C como producto de las filas de A por las columnas de B.

              Resolución explicada

              El elemento Cij es (fila i de A)·(columna j de B). Con A = −1−10−3−10122 y B = −2−22−11−1−31−1: C₁₁ = (−1, −1, 0)·(−2, −1, −3) = 2 + 1 + 0 = 3.

              Ejercicio 1 (c, d) · columnas y filas como combinaciones

              c) Calcula la primera columna de C como combinación lineal de las columnas de A. d) Calcula la primera fila de C como combinación lineal de las filas de B.

              Resolución explicada

              Las dos lecturas

              Cada columna de C es combinación de las columnas de A con los coeficientes de la columna correspondiente de B: Cj = b1jA1 + b2jA2 + ⋯. Cada fila de C es combinación de las filas de B con los coeficientes de la fila de A: Ci = ai1B1 + ai2B2 + ⋯.

              C¹ = −2·(−1, −3, 1) − 1·(−1, −1, 2) − 3·(0, 0, 2) = (2, 6, −2) + (1, 1, −2) + (0, 0, −6) = (3, 7, −10). C₁ = −1·(−2, −2, 2) − 1·(−1, 1, −1) + 0·(…) = (3, 1, −1).

show(A[0,0]*B[0,:] + A[0,1]*B[1,:] + A[0,2]*B[2,:])   # primera fila de C
              Ejercicio 1 (e, f) · suma de matrices de rango 1

              e) Calcula C como suma de las columnas de A por las filas de B. f) Comprueba que cada sumando es una matriz de rango 1.

              Resolución explicada

              C = A¹B₁ + A²B₂ + A³B₃, donde cada AⁱBᵢ es (columna i de A, n × 1)·(fila i de B, 1 × n): una matriz n × n cuyas filas son todas múltiplos de Bᵢ, así que tiene rango 1. Es la misma idea que la SVD como suma de matrices de rango 1 (tema 4).

              Ejercicio 1 (g) · propuesto: C₃₃

              Calcula el elemento C₃₃.

              Resolución explicada

              C₃₃ = (fila 3 de A)·(columna 3 de B) = (1, 2, 2)·(2, −1, −1) = 2 − 2 − 2.

              Ejercicio 2 · Tiempo de resolución

              Tres sistemas de 4 × 4, 40 × 40 y 400 × 400 con coeficientes reales.

              Ejercicio 2 (a, b) · rref() frente a solve_right()

              a) Resuelve los tres sistemas con rref() y observa el tiempo. b) Resuélvelos con solve_right() y compara.

              Resolución explicada

              Ejercicio 2

              A, B, C = load('ejercicio2Matrices.sobj')
a, b, c = load('ejercicio2Independientes.sobj')
for M, v in [(A, a), (B, b), (C, c)]:
    n = M.nrows()
    t = walltime(); M.augment(v).rref(); t1 = walltime(t)
    t = walltime(); M.solve_right(v); t2 = walltime(t)
    print(f"{n} x {n}:  rref {t1:.4f} s   solve_right {t2:.4f} s")

              Con 4 incógnitas da igual, pero con 400 rref() tarda segundos y solve_right() milésimas: rref calcula la reducida completa (y aquí con números reales en Python), mientras que solve_right usa una factorización LU optimizada (tema 2, práctica 3). Conclusión: para resolver, solve_right; rref sólo cuando quieras ver la reducida.

              Ojo con los reales

              Con números de coma flotante, la reducida tiene entradas como 2,7·10⁻¹⁷ donde debería haber 0: errores de redondeo. Por eso con reales no se compara con == sino viendo que la diferencia es muy pequeña.

              Ejercicio 3

              Ejercicio 3 · Sistemas diagonales

              Tres sistemas con matriz diagonal (4, 40 y 400 incógnitas).

              Ejercicio 3 (a, b, c) · dividir y nada más

              a) Comprueba que las matrices son diagonales. b) Resuelve usando que lo son (xᵢ = bᵢ / aᵢᵢ) y mide el tiempo. c) Resuélvelos con solve_right() y compara.

              Resolución explicada

              Si A es diagonal, cada ecuación es aᵢᵢxᵢ = bᵢ: basta dividir (n operaciones). Para el de 4 × 4, A = diag(5, 5, −3, −3) y b = (2, 3, −1, 2), luego x = (2/5, 3/5, 1/3, −2/3).

              Ejercicio 3

              A, B, C = load('ejercicio3Matrices.sobj')
a, b, c = load('ejercicio3Independientes.sobj')
print(A.is_diagonal(), B.is_diagonal(), C.is_diagonal())
print([a[i, 0] / A[i, i] for i in range(4)])
for M, v in [(A, a), (B, b), (C, c)]:
    n = M.nrows()
    t = walltime(); x = [v[i, 0] / M[i, i] for i in range(n)]; t1 = walltime(t)
    t = walltime(); y = M.solve_right(v); t2 = walltime(t)
    print(f"{n}: dividiendo {t1:.5f} s, solve_right {t2:.5f} s, iguales: {vector(x) == y.column(0)}")

              Dividir es instantáneo incluso con 400 incógnitas; solve_right también es rápido, pero no sabe que la matriz es diagonal y hace más trabajo del necesario.

              Ejercicio 5

              Ejercicio 5 · Sistemas ortogonales

              Tres sistemas cuya matriz M cumple M·Mᵗ = Mᵗ·M = I.

              Ejercicio 5 (a, b, c) · la inversa es la traspuesta

              a) Comprueba que M·Mᵗ = Mᵗ·M = Id (matrices ortogonales). b) Resuelve los sistemas usando esa propiedad y mide el tiempo. c) Resuélvelos con rref() y compara.

              Resolución explicada

              Si M es ortogonal, M−1 = Mt, así que M·x = b ⇒ x = Mᵗ·b: un solo producto matriz por vector, sin resolver nada.

              Ejercicio 5

              A, B, C = load('ejercicio5Matrices.sobj')
a, b, c = load('ejercicio5Independientes.sobj')
print(A.dimensions(), B.dimensions(), C.dimensions())
print(A.is_unitary(), B.is_unitary(), C.is_unitary())
print((A * A.transpose() - identity_matrix(4)).norm() < 1e-12)   # con reales, «casi» la identidad
for M, v in [(A, a), (B, b), (C, c)]:
    t = walltime(); x = M.transpose() * v; t1 = walltime(t)
    t = walltime(); r = M.augment(v).rref(); t2 = walltime(t)
    print(M.nrows(), f"traspuesta {t1:.4f} s, rref {t2:.4f} s, error {(M * x - v).norm():.1e}")

              El producto por la traspuesta es casi instantáneo; rref en el de 400 tarda varios segundos. Con reales, A·Aᵗ da 0,9999999… y 10⁻¹⁶ en vez de 1 y 0: por eso is_unitary() tolera un pequeño error.

              Ejercicio 6

              Ejercicio 6 · Resolver con factorizaciones

              Cada matriz de ejercicio6Matrices.sobj es el producto de un par de matrices de ejercicio6Factores.sobj.

              Ejercicio 6 (a–d) · un sistema difícil = dos fáciles

              a) Calcula el tamaño de cada sistema. b) Averigua qué tipo de matrices son los factores. c) Comprueba que el producto de cada par da la matriz del sistema. d) Elige una forma adecuada de resolver cada sistema.

              Resolución explicada

              Si M = F₁·F₂, el sistema F₁·(F₂·x) = b se resuelve en dos pasos: primero F₁·y = b y después F₂·x = y. Si los factores son triangulares u ortogonales, cada paso es inmediato.

              • A (40 × 40) = T1[0]·T1[1], con T1[0] triangular superior y T1[1] triangular inferior: hacia atrás y luego hacia delante.
              • B (30 × 30) = T2[0]·T2[1], inferior por superior (una LU): hacia delante y luego hacia atrás.
              • C (50 × 50) = T3[0]·T3[1], con T3[0] ortogonal y T3[1] triangular superior (una QR): F₂·x = F₁ᵗ·c y hacia atrás.

              Ejercicio 6 (necesita resolucion_triangular)

              A, B, C = load('ejercicio6Matrices.sobj')
a, b, c = load('ejercicio6Independientes.sobj')
T1, T2, T3 = load('ejercicio6Factores.sobj')
print(A.dimensions(), B.dimensions(), C.dimensions())
print(T1[0] * T1[1] == A, T1[0].is_triangular("upper"), T1[1].is_triangular("lower"))
y = resolucion_triangular(T1[0], a)                       # F1 y = a  (superior)
x = resolucion_triangular(T1[1], y, inferior=True)   # F2 x = y (inferior)
print("A:", A * x == a)
print(T2[0] * T2[1] == B, T2[0].is_triangular("lower"), T2[1].is_triangular("upper"))
y = resolucion_triangular(T2[0], b, inferior=True)
x = resolucion_triangular(T2[1], y)
print("B:", B * x == b)
print(T3[0] * T3[1] == C, T3[0].is_unitary(), T3[1].is_triangular("upper"))
x = resolucion_triangular(T3[1], T3[0].transpose() * c)
print("C: error", (C * x - c).norm())

              En el sistema C la comprobación con == da False porque hay números reales: la norma del error, del orden de 10⁻¹³, demuestra que la solución es correcta salvo redondeo.
