            0.1Órdenes de la práctica

            • Escalonar con letras: R.<x,y,z> = QQ[] crea un anillo de polinomios con variables x, y, z; con column_matrix(R, …) se pueden poner letras en la matriz. Se escalona con echelon_form(), nunca con rref(): rref divide por las letras como si fueran números distintos de 0 y deja una identidad sin información.
            • A.right_kernel(): el núcleo Nuc(A) (soluciones de A·x = 0); .basis() da una base y A.right_kernel_matrix() la pone en filas.
            • from geometria import * carga el módulo de dibujo de la asignatura (geometria.py; en esta página ya está en la sesión): ejes(), vectores([u, v]), plano(ec='x-y+z=0'), recta(ec=['…', '…']) y ayuda('plano') para ver los parámetros. Los dibujos se suman con +.

            Ejercicio 2 · Base y dimensión

            Para cada subespacio dado en implícitas, una base y su dimensión: es resolver el sistema homogéneo.

            Ejercicio 2 (a, b, c) · con right_kernel

            a) W = {x − y + 3z = 0}. b) W = {2x − 2y + 5z = 0, 4x − y + 3z = 0}. c) W = {x − z + t = 0, 2x + y + t = 0} ⊆ ℝ⁴.

            Resolución explicada

            W = Nuc(H), donde H tiene en sus filas los coeficientes (que son vectores perpendiculares a W). dim W = n − rg H.

            a) A mano: x = a, z = b (libres) ⇒ y = a + 3b: (x, y, z) = a(1, 1, 0) + b(0, 3, 1). Base {(1, 1, 0), (0, 3, 1)}, dimensión 2 (plano).

            Ejercicio 2 (a, b, c)

            Ejercicio 3

            Ejercicio 3 · Comparar subespacios

            Para cada par: ¿alguno contiene al otro?, ¿son iguales?, base y dimensión de la intersección, y dibujarlos.

            Ejercicio 3 (a) · propuesto: en ℝ²

            W₁ = ⟨(1, 1)⟩, W₂ = {x + 2y = 0}.

            Resolución explicada

            (1, 1) no cumple x + 2y = 0 (da 3): W₁ ⊄ W₂. Son dos rectas distintas por el origen, así que tampoco W₂ ⊂ W₁ y se cortan sólo en el origen.

            ResultadoNinguno contiene al otro; W₁ ∩ W₂ = {0}

            Ejercicio 3 (b) · un plano y una recta

            W₁ = ⟨(1, 1, 1), (1, 2, 2)⟩, W₂ = {x − y + 3z = 0, 2x − 3y = 0}.

            Resolución explicada

            W₁: los dos generadores son independientes (plano). Implícitas: escalonando (1 1 | x; 1 2 | y; 1 2 | z) sale la condición −y + z = 0. W₂: dos ecuaciones independientes en ℝ³, una recta, de director (1, −1, 3) × (2, −3, 0) = (9, 6, −1).

            • W₂ ⊂ W₁? (9, 6, −1) da −6 − 1 = −7 ≠ 0: no.
            • W₁ ⊂ W₂? Imposible: dim 2 > 1. Distintos.

            Ejercicio 5

            Ejercicio 5 · Ajustes de color

            Filtros de color como vectores de ℝ³ (R, G, B): una familia de filtros W₁ y una restricción de hardware W₂.

            Ejercicio 5 (a, b) · filtros seguros y variedad total

            W₁ = ⟨(1, 0, 1), (0, 1, 1)⟩ (ajustes magenta y cian) y W₂ = {R − G + 3B = 0}. a) ¿Qué filtros de W₁ son seguros (están en W₂)? b) ¿Qué variedad de ajustes se obtiene combinando las dos familias?

            Resolución explicada

            a) Es la intersección. Implícita de W₁: (R, G, B) = a(1, 0, 1) + b(0, 1, 1) ⇒ B = R + G, es decir −R − G + B = 0. Con la de W₂: −2G + 4B = 0 ⇒ G = 2B, y R = −B.

            Resultadoa) W₁ ∩ W₂ = ⟨(−1, 2, 1)⟩: una única dirección de filtros seguros

            b) Es la suma: se juntan los generadores de W₁ con los de W₂ = ⟨(1, 1, 0), (0, 3, 1)⟩. Los cuatro tienen rango 3:

            Resultadob) W₁ + W₂ = ℝ³ (Grassmann: 2 + 2 − 1 = 3)

            Ejercicio 8 · recomendador de películas

            Cada película de la base de datos MovieLens se representa por un vector, de forma que películas parecidas tienen vectores parecidos. Un usuario ha visto 25 películas de Disney y Pixar (Blancanieves, Pinocho, Cenicienta… Toy Story, Buscando a Nemo). a) Construye el subespacio que generan sus vectores. b) Busca las 10 películas, con al menos 30 votos, más próximas a ese subespacio. ¿Cuáles le recomendarías?

            Resolución explicada

            La «proximidad» a un subespacio W es la distancia de v a su proyección: ‖v − proyW(v)‖, dividida por ‖v‖ para no favorecer vectores cortos. Para proyectar se ortonormaliza antes la base de W con Gram-Schmidt (tema 2) y se suman las proyecciones sobre cada vector.

            Ejercicio 8 (descarga 12 MB la primera vez)

            pelicula_vectores = load('pelicula_vectores.sobj'); movie_titles = load('movie_titles.sobj')
movie_to_idx = load('movie_to_idx.sobj'); votos = load('votos_por_pelicula.sobj')
movie_ids = load('movie_ids.sobj'); num_p = load('num_p.sobj')
def buscar_idx(nombre):
    for m_id, titulo in movie_titles.items():
        if nombre.lower() in titulo.lower() and m_id in movie_to_idx:
            return movie_to_idx[m_id]
vistas = ["Snow White and the Seven Dwarfs", "Pinocchio", "Cinderella", "Alice in Wonderland", "Peter Pan",
          "Lady and the Tramp", "Sleeping Beauty", "101 Dalmatians", "Sword in the Stone, The", "Jungle Book, The",
          "Aristocats, The", "Fox and the Hound, The", "Little Mermaid, The", "Beauty and the Beast", "Aladdin",
          "Lion King, The", "Pocahontas", "Hunchback of Notre Dame, The", "Hercules", "Mulan", "Toy Story",
          "Toy Story 2", "Bug's Life, A", "Monsters, Inc.", "Finding Nemo"]
indices = [i for i in (buscar_idx(t) for t in vistas) if i is not None]
base = []                                    # Gram-Schmidt
for v in (pelicula_vectores[i] for i in indices):
    w = v - sum((v * b) * b for b in base)
    if w.norm() > 1e-6: base.append(w / w.norm())
res = []
for i in range(num_p):
    if i in indices or votos[i] < 30: continue
    v = pelicula_vectores[i]
    if v.norm() < 1e-6: continue
    proy = sum((v * b) * b for b in base)
    res.append(((v - proy).norm() / v.norm(), movie_titles.get(movie_ids[i])))
for k, (d, t) in enumerate(sorted(res)[:10], 1): print(k, round(d, 4), t)
