          Práctica 8 · Construir figuras en 3D C + r(cos θ·u + sin θ·v)

          Con una base ortonormal {u, v, w} adaptada a un plano, cualquier figura plana se coloca donde queramos: sus vértices son C + r(cos θ·u + sin θ·v), y se levanta en altura con múltiplos de w. Con esa única idea se construyen polígonos, estrellas, pirámides, prismas y objetos compuestos.

          P1P2P3P4P5P6P7P8P9SageMath
          Intenta cada ejercicio antes de abrir su resolución y márcalo como hecho.

          Práctica 8

          La receta común

          Todas las figuras de la práctica salen de los mismos tres pasos.

          0.1Base adaptada y vértices

          1. Base ortonormal adaptada. Si nos dan un plano con directores u, v: w = u × v es la normal; se normaliza u, w y se recalcula v = w × u (así v queda en el plano y perpendicular a u). Si nos dan una recta con director u (la figura es perpendicular a ella): u es la normal, v = (−u₂, u₁, 0) es perpendicular a u y w = u × v. Si nos dan un plano en implícitas, su normal son los coeficientes.
          2. Polígono regular de n lados, centro C y radio r en el plano de u, v: Pk = C + r(cos(2πk/n)·u + sin(2πk/n)·v), k = 0, …, n − 1. Como u y v son ortonormales, todos distan r de C y forman ángulos iguales.
          3. Estrella de n puntas: 2n vértices alternando dos radios r₁ (puntas) y r₂ (huecos) con ángulo π/n entre ellos.

          Para dar volumen: piramide(base + [cúspide]) y prisma(base + tapa), donde la tapa es la base desplazada h·w. poligono(lista) dibuja la figura plana.

          Las dos funciones de esta página

          Las celdas usan regular(C, u, v, r, n) y estrella(C, u, v, r1, r2, n). Se definen solas al ejecutar la primera celda (junto con from geometria import *), pero aquí tienes su código para usarlas en tu SageMath:

          Funciones auxiliares

          def regular(C, u, v, r, n, fase=0):
    return [C + r*(cos(2*pi*k/n + fase)*u + sin(2*pi*k/n + fase)*v) for k in range(n)]
def estrella(C, u, v, r1, r2, n, fase=0):
    return [C + (r1 if k % 2 == 0 else r2)*(cos(pi*k/n + fase)*u + sin(pi*k/n + fase)*v) for k in range(2*n)]
O = vector([0, 0, 0]); e1, e2 = vector([1, 0, 0]), vector([0, 1, 0])
poligono(regular(O, e1, e2, 1, 6)) + poligono(estrella(O + vector([3, 0, 0]), e1, e2, 1, 0.4, 5), color=azul)

          Ejercicio 1

          Ejercicio 1 · Polígonos y estrellas

          Figuras planas paralelas a un plano o perpendiculares a una recta.

          Ejercicio 1 (a) · octógono paralelo a un plano

          Dado Π = ⟨(1, 0, 1), (1, 3, 1)⟩, construye un polígono de 8 lados paralelo a ese plano a distancia 2.

          Resolución explicada

          Normal: (1, 0, 1) × (1, 3, 1) = (−3, 0, 3), así que w = (−1, 0, 1)/√2. u = (1, 0, 1)/√2 y v = w × u = (0, 1, 0). Π pasa por el origen, de modo que el plano paralelo a distancia 2 pasa por C = 2w = (−√2, 0, √2). El octógono (radio 1, por ejemplo) es C + cos(kπ/4)·u + sin(kπ/4)·v.

          ResultadoCentro (−√2, 0, √2), base {u, v} = {(1, 0, 1)/√2, (0, 1, 0)}; vale también C = −2w (al otro lado)

          Ejercicio 1 (a)

          u, v = vector([1, 0, 1]), vector([1, 3, 1])
w = u.cross_product(v).normalized(); u = u.normalized(); v = w.cross_product(u)
C = 2*w
plano([u, v]) + poligono(regular(C, u, v, 1, 8), color=verde, wire=True) + vectores([u, v, w], inicio=[C, C, C]) + ejes()
          Ejercicio 1 (b) · hexágono perpendicular a una recta

          Dada r = ⟨(1, 2, −1)⟩, construye un polígono de 6 lados con centro en el origen y perpendicular a la recta.

          Resolución explicada

          Ahora el director es la normal: u = (1, 2, −1)/√6. v = (−2, 1, 0)/√5 (perpendicular a u) y w = u × v = (1, 2, 5)/√30. El hexágono vive en el plano de v y w: Pk = cos(kπ/3)·v + sin(kπ/3)·w.

          ResultadoHexágono en el plano x + 2y − z = 0 con base {(−2, 1, 0)/√5, (1, 2, 5)/√30}

          Ejercicio 1 (b)

          u = vector([1, 2, -1]).normalized(); v = vector([-u[1], u[0], 0]).normalized(); w = u.cross_product(v)
O = vector([0, 0, 0])
recta(u) + poligono(regular(O, v, w, 1, 6), wire=True) + vectores([u, v, w]) + ejes()
          Ejercicio 1 (c) · estrella perpendicular a una recta

          Dada r = {x − y + z = 0, x − 2z = 0}, construye una estrella de 5 puntas centrada en el origen, perpendicular a la recta y cuyos vértices (las puntas) disten 2 del origen.

          Resolución explicada

          Director: (1, −1, 1) × (1, 0, −2) = (2, 3, 1). Base: u = (2, 3, 1)/√14, v = (−3, 2, 0)/√13, w = u × v = (−2, −3, 13)/√182. La estrella alterna radio 2 (puntas) y uno menor, por ejemplo 0,8, cada π/5.

          ResultadoEstrella de 10 vértices en el plano 2x + 3y + z = 0, puntas a distancia 2

          Ejercicio 1 (c)

          u = vector([1, -1, 1]).cross_product(vector([1, 0, -2])).normalized()
v = vector([-u[1], u[0], 0]).normalized(); w = u.cross_product(v)
O = vector([0, 0, 0])
recta(ec=['x-y+z=0', 'x-2*z=0']) + poligono(estrella(O, v, w, 2, 0.8, 5), color=rojo, wire=True) + vectores([u, v, w])

          En el cuaderno de bases

          La celda de este apartado usa v sin haberla definido (arrastra la del apartado anterior). Hay que construir v perpendicular a u, como arriba.

          Ejercicio 1 (d) · hexágono con centro fuera del origen

          Dada la recta por P = (1, 1, 1) con director (1, 0, 1), construye un polígono de 6 lados con centro en P y perpendicular a la recta.

          Resolución explicada

          u = (1, 0, 1)/√2; v = (−u₂, u₁, 0) normalizado = (0, 1, 0); w = u × v = (−1, 0, 1)/√2. Vértices P + cos(kπ/3)·v + sin(kπ/3)·w.

          ResultadoHexágono centrado en (1, 1, 1) en el plano x + z = 2

          Ejercicio 1 (d)

          P = vector([1, 1, 1]); u = vector([1, 0, 1]).normalized()
v = vector([-u[1], u[0], 0]).normalized(); w = u.cross_product(v)
recta(u, C=P) + poligono(regular(P, v, w, 1, 6), color=azul, wire=True) + vectores([u, v, w], inicio=[P, P, P])

          Ejercicio 2

          Ejercicio 2 · Pirámides y prismas

          La base es un polígono regular; la altura va en la dirección normal.

          Ejercicio 2 (a) · pirámide pentagonal

          Una pirámide de altura 5 cuya base es un pentágono regular inscrito en una circunferencia de radio 1 contenido en el plano x − y + z = 0.

          Resolución explicada

          w = (1, −1, 1)/√3, u = (1, 1, 0)/√2 (en el plano: 1 − 1 = 0), v = w × u = (−1, 1, 2)/√6. Base: el pentágono de radio 1 centrado en el origen; cúspide 5w (a distancia 5 del plano).

          Resultadopiramide(pentágono + [5w]), con 5w = (5, −5, 5)/√3

          Ejercicio 2 (a)

          w = vector([1, -1, 1]).normalized(); u = vector([-w[1], w[0], 0]).normalized(); v = w.cross_product(u)
O = vector([0, 0, 0])
plano(ec='x-y+z=0') + piramide(regular(O, u, v, 1, 5) + [5*w], wire=True) + vectores([u, v, w])
          Ejercicio 2 (b) · prisma hexagonal

          Un prisma de altura 3 cuya base es un hexágono regular de lado 1 contenido en el plano 2x − y + z = 0.

          Resolución explicada

          En el hexágono regular el lado es igual al radio, así que r = 1. w = (2, −1, 1)/√6, u = (1, 2, 0)/√5, v = w × u = (−2, 1, 5)/√30. Tapa = base + 3w.

          Resultadoprisma(base + [P + 3w para cada P de la base])

          Ejercicio 2 (b)

          w = vector([2, -1, 1]).normalized(); u = vector([-w[1], w[0], 0]).normalized(); v = w.cross_product(u)
base = regular(vector([0, 0, 0]), u, v, 1, 6)
plano(ec='2*x-y+z=0') + prisma(base + [P + 3*w for P in base], color=azul, wire=True)

          El cuaderno de bases normaliza w tres veces pero nunca u: con u sin normalizar el hexágono sale deformado (más ancho en una dirección).

          Ejercicio 2 (c) · prisma entre dos planos paralelos

          Un prisma hexagonal con la base en el plano x + y + 2z = 1, la tapa en el plano paralelo que pasa por el origen (centrada en el origen) y con (1, −2, 1) como uno de sus vértices.

          Resolución explicada

          Normal n = (1, 1, 2)/√6. El centro de la base es la proyección del origen sobre el plano: C₀ = 16(1, 1, 2), y la altura es la distancia entre los planos, 1/√6. El vértice dado está en el plano (1 − 2 + 2 = 1) y C₀V = (5/6, −13/6, 2/3) es perpendicular a n, así que tomamos u = C₀V/‖C₀V‖ y el radio R = ‖C₀V‖ = √210/6 ≈ 2,42. v = n × u. La tapa es la base menos C₀.

          ResultadoBase: C₀ + R(cos(kπ/3)u + sin(kπ/3)v), con k = 0 en (1, −2, 1); tapa: base − (1/6, 1/6, 1/3)

          Ejercicio 2 (c)

          n = vector([1, 1, 2]).normalized(); C0 = vector([1, 1, 2]) / 6; V = vector([1, -2, 1])
R = (V - C0).norm(); u = (V - C0) / R; v = n.cross_product(u)
base = regular(C0, u, v, R, 6); tapa = [P - C0 for P in base]
print(R, base[0])
plano(ec='x+y+2*z=1', l=8) + plano(ec='x+y+2*z=0', l=8, color=azul) + prisma(base + tapa, wire=True) + puntos([V], g=30)

          (En la versión «con bases» del enunciado la base está centrada en (0, 1, 0): entonces u = ((1, −2, 1) − (0, 1, 0))/‖·‖ = (1, −3, 1)/√11 y la tapa es la base desplazada −(1/√6)·n.)

          Ejercicio 3

          Ejercicio 3 · Objetos compuestos

          Se combinan varias pirámides y prismas con la misma base adaptada.

          Ejercicio 3 (a) · bipirámide octogonal

          Recta por C = (1, −1, 1) con director u = (1, 1, 2). La parte central es un octógono centrado en C, radio 1 y perpendicular a la recta, y los picos distan 2 de C.

          Resolución explicada

          u = (1, 1, 2)/√6, v = (−1, 1, 0)/√2, w = u × v = (−1, −1, 1)/√3. Octógono C + cos(kπ/4)·v + sin(kπ/4)·w; los picos están sobre la recta: C ± 2u. Son dos pirámides con la misma base.

          Resultadopiramide(oct + [C + 2u]) + piramide(oct + [C − 2u])

          Ejercicio 3 (a)

          C = vector([1, -1, 1]); u = vector([1, 1, 2]).normalized()
v = vector([-u[1], u[0], 0]).normalized(); w = u.cross_product(v)
oct = regular(C, v, w, 1, 8)
recta(u, C=C) + piramide(oct + [C + 2*u], color=verde, wire=True, opacidad=1) + piramide(oct + [C - 2*u], color=verde, wire=True, opacidad=1)
          Ejercicio 3 (b) · el diamante

          Plano por C = (1, 0, 1) con directores u = (1, 0, 0,3) y v = (0, 1, −0,3). El vértice del diamante está en C y las otras dos filas de vértices son octógonos paralelos al plano, a distancias 3 y 4, con radios 2 y 1,3.

          Resolución explicada

          w = u × v = (−0,3, 0,3, 1) normalizado; u normalizado y v = w × u. Fila 1: octógono de radio 2 centrado en C + 3w; fila 2: radio 1,3 centrado en C + 4w. La parte de abajo es una pirámide invertida (cúspide C) y la de arriba un prisma (tronco) entre los dos octógonos, con la tapa incluida.

          Resultadopiramide(fila₁ + [C]) + prisma(fila₁ + fila₂)

          Ejercicio 3 (b)

          C = vector([1, 0, 1]); u, v = vector([1, 0, 3/10]), vector([0, 1, -3/10])
w = u.cross_product(v).normalized(); u = u.normalized(); v = w.cross_product(u)
f1, f2 = regular(C + 3*w, u, v, 2, 8), regular(C + 4*w, u, v, 13/10, 8)
plano([u, v], C=C, l=10, g=10) + piramide(f1 + [C], color=verde, wire=True, opacidad=1) + prisma(f1 + f2, color=verde, wire=True, opacidad=1)
          Ejercicio 3 (c) · estrella con grosor

          Mismo plano. La base de la estrella está centrada en C, tiene 8 puntas, sus vértices están a distancias 0,5 y 0,25 y la altura es 0,1.

          Resolución explicada

          Base: estrella(C, u, v, 0.5, 0.25, 8), 16 vértices. Tapa: los mismos desplazados 0,1·w. Un prisma con 16 + 16 vértices.

          Resultadoprisma(base + [P + 0,1·w para P en base])

          Ejercicio 3 (c)

          C = vector([1, 0, 1]); u, v = vector([1, 0, 3/10]), vector([0, 1, -3/10])
w = u.cross_product(v).normalized(); u = u.normalized(); v = w.cross_product(u)
base = estrella(C, u, v, 1/2, 1/4, 8)
plano([u, v], C=C, l=2, g=2) + prisma(base + [P + w/10 for P in base], color=verde, wire=True, opacidad=1) + vectores([u, v, w], inicio=[C, C, C])

          Opcionales

          Ejercicios 4 a 6 · Opcionales

          Sobre el plano por C = (1, 0, 1) con directores (1, 1, 1) y (0, −1, 2). Los tamaños son libres.

          Ejercicio 4 · corona de estrellas

          Una estrella de 8 puntas en el centro y, alrededor, 8 estrellas de 6 puntas alternando colores.

          Resolución explicada

          Como (1, 1, 1)·(0, −1, 2) = 1 ≠ 0, primero se ortonormaliza: u normalizado, w = u × v normalizado, v = w × u. Los centros de las estrellas pequeñas son un octógono de radio 5: regular(C, u, v, 5, 8). Cada estrella es un prisma de altura 0,3.

          Ejercicio 4

          C = vector([1, 0, 1]); u = vector([1, 1, 1]).normalized()
w = u.cross_product(vector([0, -1, 2])).normalized(); v = w.cross_product(u)
def con_grosor(base, col): return prisma(base + [P + 0.3*w for P in base], opacidad=1, color=col)
ob = plano([u, v], C=C, l=15, g=15) + con_grosor(estrella(C, u, v, 2, 1, 8), rojo)
for j, Cj in enumerate(regular(C, u, v, 5, 8)):
    ob += con_grosor(estrella(Cj, u, v, 1.5, 0.75, 6), verde if j % 2 == 0 else azul)
ob.show(frame=False)
          Ejercicio 5 · marco pentagonal

          Un pentágono hueco (un marco) con grosor y altura.

          Resolución explicada

          Dos pentágonos concéntricos de radios 2 y 2,5. Cada lado del marco es un prisma de base trapecial con los vértices Pi, Pi+1, Qi+1, Qi (índices módulo 5) y altura h·w.

          Ejercicio 5

          C = vector([1, 0, 1]); u = vector([1, 1, 1]).normalized()
w = u.cross_product(vector([0, -1, 2])).normalized(); v = w.cross_product(u)
P, Q = regular(C, u, v, 2, 5), regular(C, u, v, 2.5, 5)
ob = plano([u, v], C=C, l=8, g=8)
for i in range(5):
    trapecio = [P[i], P[(i + 1) % 5], Q[(i + 1) % 5], Q[i]]
    ob += prisma(trapecio + [X + w for X in trapecio], opacidad=1, wire=True)
ob.show(frame=False)
          Ejercicio 6 · pirámide escalonada

          Una pirámide de pisos cuadrados que se van estrechando.

          Resolución explicada

          Cada piso es un prisma de base cuadrada (cuatro vértices con regular(…, 4)) cuya tapa es un poco más pequeña (radio − 0,3, así se ve el bisel de la figura). El piso siguiente arranca en la tapa con el radio reducido un 10 %.

          Ejercicio 6

          C = vector([1, 0, 1]); u = vector([1, 1, 1]).normalized()
w = u.cross_product(vector([0, -1, 2])).normalized(); v = w.cross_product(u)
ob = plano([u, v], C=C, l=12, g=12, color=verde, opacidad=1)
r, h = 4, 0.4
for piso in range(6):
    base = regular(C, u, v, r, 4)
    tapa = [X + h*w for X in regular(C, u, v, r - 0.3, 4)]
    ob += prisma(base + tapa, color=gris, wire=True, opacidad=1)
    C, r = C + h*w, 0.9*(r - 0.3)
ob.show(frame=False)

          Construye la figura sobre el plano por (1, −1, 1) con normal (1, 1, 2) en lugar del plano pedido, y hace h*=prop2 con una h que no existe en esa celda (la altura se llama h1). Aquí está corregido.
