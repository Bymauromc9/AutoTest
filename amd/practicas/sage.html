1.1Consola libre

Pulsa Ejecutar en SageMath: la celda se convierte en un editor. Cambia el código y vuelve a ejecutarlo tantas veces como quieras (también con Mayús + Intro). Todas las celdas de esta página comparten la sesión: lo que definas en una lo puedes usar en las demás. En la sesión ya está el módulo de dibujo de la asignatura (from geometria import * ya se ha ejecutado).

En las páginas de las prácticas, cada ejercicio tiene además su cuaderno Tu SageMath: celdas para escribir tus propias órdenes (introducir matrices, escalonar, comprobar…) antes de mirar la resolución. Añade tantas celdas como quieras para separar las partes del ejercicio; se ejecutan una a una o todas a la vez, y tu código se guarda en este navegador.

Consola

A = matrix(QQ, [[2, 1, 1], [1, 3, 2], [1, 0, 0]])
show(A, A.det(), A.inverse())

1.2Cómo funciona y por qué así

El código no se ejecuta en tu navegador sino en los servidores públicos de SageMathCell, del propio proyecto SageMath. La web sólo carga su pequeño cliente cuando pulsas el primer botón, así que las páginas siguen siendo ligeras y funcionan igual en el móvil.

  • JupyterLab con SageMath necesita instalar SageMath (varios GB) o mantener un servidor encendido: no tiene sentido para una web estática.
  • JupyterLite (Python dentro del navegador) es ligero, pero SageMath no funciona en él: habría que reescribir todo en sympy y numpy y el código ya no sería el de clase.
  • SageMathCell ejecuta el SageMath de verdad, con las mismas órdenes que en el aula, sin instalar nada y sin coste para la web. A cambio necesita conexión, la sesión se cierra tras 15 minutos sin uso (al recargar la página empieza otra) y los cálculos muy largos se cortan. Además, por seguridad, una celda sólo puede descargar de unos pocos sitios (GitHub sí, esta web no): por eso es tu navegador el que manda a la sesión los ficheros de cada práctica, y los muy grandes los descarga el servidor del repositorio de la web en GitHub.

Si quieres SageMath en tu ordenador

CoCalc (cocalc.com) da cuadernos de SageMath gratis en el navegador. Para instalarlo: en Linux o macOS con conda-forge (conda create -n sage sage); en Windows dentro de WSL con el mismo método, o con la imagen de Docker sagemath/sagemath. Después sage -n jupyter abre los cuadernos de las prácticas.

Chuleta

Chuleta · Lo básico

Cálculo exacto, variables, ecuaciones y la forma de mostrar resultados.

2.1Números, variables y ecuaciones

  • SageMath calcula exacto: 1/3 + 1/6 da 1/2 y sqrt(8) da 2*sqrt(2). Para decimales, n(x) o N(x, digits=20).
  • var('x y z') declara incógnitas; solve([ecuaciones], x, y) resuelve; == escribe una ecuación.
  • show(…) lo muestra bonito; latex(…) da su código LaTeX; print(…) en texto.
  • Potencias con ^ o **; expand, factor, simplify_full.

Lo básico

print(1/3 + 1/6, sqrt(8), n(pi, digits=15))
var('x y')
show(solve([2*x + y == 3, x - y == 0], x, y))
show(factor(x^3 - x), expand((x + 1)^3))

Prácticas 1 a 3

Chuleta · Matrices y sistemas

Construir matrices, operar, escalonar y resolver.

3.1Matrices

  • matrix(QQ, [[…], […]]): por filas (QQ = racionales exactos). vector([…]), identity_matrix(n), zero_matrix(m, n), random_matrix(ZZ, m, n).
  • A*B, A + B, A^k, A.transpose() (o A.T), A.inverse() (o A^-1), A.det(), A.rank(), A.trace().
  • Elementos y trozos: A[i, j], A.row(i), A.column(j), A[:, 0:2] (se cuenta desde 0), A.augment(b) pega columnas, A.stack(B) pega filas.
  • A.rref(): forma escalonada reducida. A.echelon_form(): escalonada. A.pivots(): columnas pivote.
  • Operaciones elementales: A.swap_rows(i, j), A.add_multiple_of_row(i, j, c) (Fᵢ += c·Fⱼ), A.rescale_row(i, c); sus matrices: elementary_matrix(QQ, n, row1=i, row2=j).

Matrices

A = matrix(QQ, [[1, 2, 1], [2, 5, 3], [1, 3, 4]])
show(A.T, A.det(), A.rank(), A.inverse())
B = copy(A); B.add_multiple_of_row(1, 0, -2); show(B)
show(A.augment(identity_matrix(3)).rref())     # Gauss-Jordan: a la derecha queda la inversa

3.2Sistemas de ecuaciones

  • Clasificar (Rouché-Frobenius): comparar A.rank() y A.augment(b).rank() con el número de incógnitas.
  • Resolver: A.solve_right(b) da una solución (error si es incompatible); A.right_kernel() da las soluciones del homogéneo, así que la general es la particular + el núcleo.
  • A.augment(b, subdivide=True).rref() muestra la ampliada escalonada con la barra.

Sistemas

A = matrix(QQ, [[1, 1, 1], [1, 2, 3], [2, 3, 4]]); b = vector([6, 14, 20])
print(A.rank(), A.augment(b).rank())            # 2 y 2 < 3: compatible indeterminado
show(A.augment(b, subdivide=True).rref())
show(A.solve_right(b), A.right_kernel().basis())

3.3Factorizaciones LU y Cholesky

  • P, L, U = A.LU() cumple A = P·L·U (P de permutación; si P = I no ha hecho falta pivotar).
  • A.cholesky() (matriz simétrica definida positiva): L triangular inferior con A = L·Lᵗ. Sobre QQ puede necesitar raíces: usa A.change_ring(RDF) o QQbar.

LU y Cholesky

A = matrix(QQ, [[2, 1, 1], [4, 3, 3], [8, 7, 9]])
P, L, U = A.LU(); show(P, L, U, P*L*U == A)
S = matrix(RDF, [[4, 2], [2, 3]]); L = S.cholesky(); show(L, L*L.T)

Prácticas 2, 4, 5 y 6

Chuleta · Subespacios y producto escalar

Bases, dimensiones, ortogonalidad, QR y mínimos cuadrados.

4.1Subespacios

  • V = span([u, v]) (o span(QQ, …)): el subespacio generado. V.dimension(), V.basis(), w in V.
  • V + W (suma), V.intersection(W), V.complement() (el ortogonal: sus vectores son los coeficientes de unas implícitas de V).
  • Coordenadas en una base concreta: W = V.subspace_with_basis([u, v]) y W.coordinate_vector(w); o resolver column_matrix([u, v]).solve_right(w).
  • Núcleo e imagen de A: A.right_kernel() y A.column_space().

Subespacios

u, v, w = vector(QQ, [1, 0, 1, 2]), vector(QQ, [0, 1, 1, 1]), vector(QQ, [2, 3, 5, 7])
V = span([u, v]); W = span([vector(QQ, [1, 1, 0, 0]), vector(QQ, [0, 0, 1, 1])])
print(V.dimension(), w in V, (V + W).dimension(), V.intersection(W).dimension())
show(V.complement().basis())                    # implícitas de V
print(V.subspace_with_basis([u, v]).coordinate_vector(w))

4.2Producto escalar, Gram-Schmidt y QR

  • u*v o u.dot_product(v), u.norm(), u.normalized(), u.cross_product(v) (en ℝ³).
  • Proyección sobre ⟨v⟩: (u*v)/(v*v)*v. Ángulo: arccos(u*v/(u.norm()*v.norm())).
  • G, M = A.gram_schmidt(): filas de G ortogonales (sin normalizar), A = M·G. Ojo, trabaja con las filas de A.
  • Q, R = A.QR() sobre RDF (decimales) o AA (exacto con raíces): A = Q·R con Q ortogonal y R triangular superior.

Producto escalar y QR

u, v = vector([1, 2, 2]), vector([3, 0, 4])
print(u*v, u.norm(), u.cross_product(v), (u*v)/(v*v)*v)
A = matrix(QQ, [[1, 1, 0], [1, 0, 1], [0, 1, 1]])
G, M = A.gram_schmidt(); show(G, M*G == A)
Q, R = A.change_ring(AA).QR(); show(Q, R)

4.3Mínimos cuadrados

  • Ecuaciones normales: la mejor solución x̂ de Ax = b resuelve AᵗA·x̂ = Aᵗb: (A.T*A).solve_right(A.T*b).
  • Con QR: R.solve_right(Q.T*b), más estable con decimales.
  • Ajustes: find_fit(datos, modelo) con un modelo simbólico, y points(datos) + plot(…) para verlo.

Mínimos cuadrados

datos = [(0, 1), (1, 3), (2, 4), (3, 4), (4, 6)]
A = matrix(QQ, [[1, x] for x, y in datos]); b = vector(QQ, [y for x, y in datos])
c = (A.T*A).solve_right(A.T*b); print(c)        # recta y = c0 + c1·x
var('t'); points(datos, size=40) + plot(c[0] + c[1]*t, (t, -0.5, 4.5), color='red')

Prácticas 7 a 9

Chuleta · Geometría y aplicaciones lineales

El módulo geometria.py de la asignatura y las matrices de movimientos.

5.1Dibujar con geometria.py

  • from geometria import * carga el módulo (en esta página y en las prácticas ya está en la sesión e importado; para tu SageMath, descarga geometria.py y déjalo en la carpeta del cuaderno). ayuda('plano') explica los parámetros de cada función.
  • ejes(), vectores([u, v], inicio=[P, P]), puntos([P, Q], g=30), segmentos([P, Q, R]).
  • recta(u, C=P) o recta(ec=['x-y=0', 'z=1']); plano([u, v], C=P) o plano(ec='x+y+z=1').
  • Sólidos: poligono(vértices), prisma(base + tapa), piramide(base + [cúspide]), esfera(C=P, r=1).
  • Modelos: vertices, caras, colores = importarObjeto("x.obj", color=True) (con dim=2 para piezas planas) y objeto(vertices, caras, color=colores).
  • Los dibujos se suman con +; .show(frame=False) quita la caja.

geometria.py

from geometria import *
u, v = vector([1, 0, 1]), vector([0, 1, -1]); P = vector([1, 1, 1])
ejes() + plano([u, v], C=P) + vectores([u, v, u.cross_product(v)], inicio=[P, P, P]) + puntos([P], g=30)

5.2Matrices de movimientos

  • Giro en el plano: matrix([[cos(a), -sin(a)], [sin(a), cos(a)]]); en el espacio alrededor del eje Z, la misma con un 1 en la esquina.
  • Simetría respecto a ⟨u⟩: 2*u.column()*u.row()/(u*u) - identity_matrix(n); respecto al plano de normal n: identity_matrix(3) - 2*n.column()*n.row()/(n*n).
  • Proyección sobre ⟨u⟩: u.column()*u.row()/(u*u). Con una base ortonormal adaptada B (por columnas): A = B·D·Bᵗ.
  • Aplicar a un objeto: [A*vector(p) for p in vertices].

Movimientos

n = vector([1, -1, 2]); S = identity_matrix(3) - 2*n.column()*n.row()/(n*n)
show(S, S*n == -n, S^2 == 1)
a = pi/6; G = matrix([[cos(a), -sin(a)], [sin(a), cos(a)]]); show(G, G*vector([1, 0]))

Temas 4 y 5

Chuleta · Diagonalización, SVD y aritmética modular

Valores propios, la descomposición en valores singulares y las congruencias.

6.1Valores y vectores propios

  • A.charpoly() (polinomio característico, en la variable x; .factor() para ver las raíces), A.eigenvalues().
  • A.eigenvectors_right(): lista de (valor, [vectores de una base del subespacio propio], multiplicidad algebraica).
  • A.is_diagonalizable(); D, P = A.eigenmatrix_right() cumple A·P = P·D; A.jordan_form(transformation=True).
  • Subespacio propio de λ: (A - λ*identity_matrix(n)).right_kernel().

Diagonalización

A = matrix(QQ, [[2, 1, 1], [1, 2, 1], [1, 1, 2]])
show(A.charpoly().factor(), A.eigenvectors_right())
D, P = A.eigenmatrix_right(); show(D, P, P.inverse()*A*P == D)

6.2SVD

  • U, S, V = A.change_ring(RDF).SVD() cumple A = U·S·Vᵗ (U y V ortogonales, S «diagonal» con los valores singulares ordenados de mayor a menor).
  • Valores singulares exactos: raíces de los valores propios de AᵗA, (A.T*A).eigenvalues(). Rango = número de valores singulares no nulos.
  • Aproximación de rango k: sum(S[i, i]*U.column(i).column()*V.column(i).row() for i in range(k)).

SVD

A = matrix(QQ, [[3, 2, 2], [2, 3, -2]])
print((A.T*A).eigenvalues())                    # 25, 9, 0: valores singulares 5 y 3
U, S, V = A.change_ring(RDF).SVD(); show(S.n(digits=4), (U*S*V.T - A).norm() < 1e-12)

6.3Aritmética modular

  • a % n (resto), mod(a, n) o Mod(a, n) (elemento de ℤₙ: sus operaciones ya se hacen módulo n), Zmod(n) o Integers(n) (el anillo entero).
  • gcd(a, b), xgcd(a, b) → (d, s, t) con d = s·a + t·b (identidad de Bézout), lcm, factor(n), is_prime(p), euler_phi(n).
  • Inverso: inverse_mod(a, n) o 1/mod(a, n); potencias: power_mod(a, e, n).
  • Ecuaciones: solve_mod(3*x == 2, 7). Como extra (no entra en el tema 5), crt([a1, a2], [m1, m2]) resuelve sistemas de congruencias.
  • Matrices módulo n: matrix(Zmod(26), …); su inversa es la de ℤ₂₆ (cifrado de Hill).

Aritmética modular

print(gcd(240, 46), xgcd(240, 46), inverse_mod(7, 26), power_mod(3, 200, 13))
print(euler_phi(26), factor(360), crt([2, 3, 2], [3, 5, 7]))
var('x'); print(solve_mod(3*x == 2, 7))
K = matrix(Zmod(26), [[3, 3], [2, 5]]); show(K.inverse(), K*K.inverse())

6.4Gráficas

  • plot(f, (x, a, b)), implicit_plot(ec, (x, …), (y, …)), points(lista), line(lista), arrow(P, Q), polygon(lista).
  • En 3D: plot3d, implicit_plot3d, point3d, line3d, arrow3d (se pueden girar con el ratón).
  • Opciones útiles: aspect_ratio=1, axes=False, color='red'; graphics_array([g1, g2]) pone varias juntas.

Gráficas

var('x y')
g1 = implicit_plot(x^2/4 + y^2 == 1, (x, -3, 3), (y, -2, 2)) + arrow((0, 0), (2, 0), color='red')
g2 = plot(sin(x)/x, (x, -10, 10))
graphics_array([g1, g2]).show()
