        Práctica 10

        Las ideas que se usan

        Una base ortonormal adaptada al problema convierte cada aplicación en una matriz diagonal o en un giro conocido.

        0.1Recetario

        • Giro de ángulo α alrededor de la recta ⟨k⟩ (k unitario): se completa k a una base ortonormal positiva B = [a b k] (a × b = k) y G = B·Rz(α)·Bᵗ, con Rz(α) = cos α−sin α0sin αcos α0001. Sin construir la base: G = cos α·I + sin α·[k]× + (1 − cos α)·kkᵗ (fórmula de Rodrigues).
        • Proyección oblicua sobre el plano n·x = 0 en la dirección d (con n·d ≠ 0): p(x) = x − n·xn·dd, es decir, P = I − d nᵗnᵗd. Si d es la normal es la proyección ortogonal.
        • Diagonalizar: A es diagonalizable si tiene n vectores propios independientes (si los autovalores son distintos, siempre). Entonces A = P·D·P⁻¹ y Aᵏ = P·Dᵏ·P⁻¹, y Dᵏ sólo eleva la diagonal.
        • Colocar un objeto: si sus coordenadas están dadas respecto de la base canónica, en la base B = [a b c] con origen C los vértices pasan a C + B·v. Para mover sin deformar, B ortonormal.

        Al ejecutar la primera celda se cargan geometria.py y la función giroZ(a) (giro alrededor del eje Z).

        Ejercicio 1

        Ejercicio 1 · Una corona de diamantes

        La recta r = ⟨(1, 0, −1)⟩ y el diamante de diamante.obj.

        Ejercicio 1 (a) · colocar el diamante

        Coloca el objeto de diamante.obj en un punto del plano perpendicular a la recta que esté a distancia 2 del origen.

        Resolución explicada

        El diamante de diamante.obj tiene su eje en el eje Z (z de 0 a 2, radio 1). El plano perpendicular a r por el origen es x − z = 0. Una base ortonormal adaptada:

        • k = (1, 0, −1)/√2, la dirección de la recta;
        • u = (1, 0, 1)/√2 y v = (0, 1, 0), en el plano.

        El punto C = 2u = (√2, 0, √2) está en el plano y a distancia 2. Para que el diamante apunte hacia fuera (dirección u) se lleva e₃ a u con la base positiva M = [k v u] (k × v = u):

        Resultadovértice colocado = C + M·v, M = 1/√201/√2010−1/√201/√2

        Ejercicio 1 (a)

        k = vector([1, 0, -1]).normalized(); u = vector([1, 0, 1]).normalized(); v = vector([0, 1, 0])
M = column_matrix([k, v, u]); show(M); print(M.det())          # 1: base positiva
C = 2*u; print(C, C.norm(), C*vector([1, 0, -1]))                 # distancia 2 y en el plano
vertices, caras, colores = importarObjeto("diamante.obj", color=True)
diamante = [C + M*vector(x) for x in vertices]
(recta(k, l=6) + plano([u, v], l=6, opacidad=0.2) + objeto(diamante, caras, color=colores)).show(frame=False)
        Ejercicio 1 (b) · el giro de 60° y la corona

        Calcula la matriz del giro de 60° alrededor de la recta y úsala para crear una corona de 6 diamantes alrededor de ella.

        Resolución explicada

        Con B = [v u k] (positiva: v × u = k) y Rz(60°), G = B·Rz·Bᵗ. Por Rodrigues, con cos 60° = 1/2, sin 60° = √3/2 y k = (1, 0, −1)/√2:

        ResultadoG = 143√6−1−√62−√6−1√63

        Comprobaciones: G·k = k (la recta queda fija), traza = 2 = 1 + 2 cos 60° y GᵗG = I. La corona son las imágenes del diamante colocado por G⁰, G¹, …, G⁵: como C está en el plano perpendicular, todas quedan en ese plano, a distancia 2 de la recta.

        Ejercicio 1 (b)

        B = column_matrix([v, u, k]); G = (B * giroZ(pi/3) * B.transpose()).simplify_full(); show(G)
print(G*k == k, G.trace(), (G.transpose()*G).simplify_full() == identity_matrix(3))
corona = recta(k, l=6)
for i in range(6):
    corona += objeto([G^i * x for x in diamante], caras, color=colores)
corona.show(frame=False)

        Ejercicio 2

        Ejercicio 2 · Proyección oblicua y sombras

        Proyectar en la dirección (1, 0, 1) sobre el plano x − y + z = 0.

        Ejercicio 2 (a) · la matriz de la proyección

        Calcula la matriz de la proyección oblicua en la dirección (1, 0, 1) sobre el plano x − y + z = 0.

        Resolución explicada

        n = (1, −1, 1), d = (1, 0, 1), n·d = 2. P = I − d nᵗ2:

        ResultadoP = 1211−1020−111

        Con una base adaptada se ve igual: a = (1, 1, 0) y b = (0, 1, 1) están en el plano (se quedan fijos) y d se anula, así que P = Q·diag(1, 1, 0)·Q⁻¹ con Q = [a b d]. Comprobaciones: P·d = 0, P·a = a, P² = P y la imagen de cualquier vector cumple x − y + z = 0. No es simétrica: no es una proyección ortogonal.

        Ejercicio 2 (a)

        n = vector([1, -1, 1]); d = vector([1, 0, 1])
P = identity_matrix(3) - d.column()*n.row()/(n*d); show(P)
Q = column_matrix([vector([1, 1, 0]), vector([0, 1, 1]), d])
print(Q*diagonal_matrix([1, 1, 0])*Q.inverse() == P, P*d, P^2 == P, n*(P*vector([3, 5, 7])))
        Ejercicio 2 (b) · la sombra de una columna

        Coloca el objeto de columna.obj perpendicular al plano. Calcula y dibuja su proyección sobre el plano (su sombra).

        Resolución explicada

        La columna tiene su eje en el eje Z (z de 0 a 8,12). Para ponerla perpendicular al plano se lleva e₃ a la normal unitaria w = (1, −1, 1)/√3 con una base ortonormal positiva:

        a = (1, 1, 0)/√2, b = w × a = (−1, 1, 2)/√6 y M = [a b w]. La columna colocada es M·v (con la base en el plano) y su sombra, P·M·v: cada vértice se desplaza en la dirección d hasta el plano. La sombra conserva las caras (es la imagen del objeto por una aplicación lineal), aunque aplastada.

        Ejercicio 2 (b)

        w = n.normalized(); a = vector([1, 1, 0]).normalized(); b = w.cross_product(a)
M = column_matrix([a, b, w]); print(M.det())
M, PR = M.change_ring(RDF), P.change_ring(RDF)      # con números reales aproximados el dibujo es más rápido
vertices, caras, colores = importarObjeto("columna.obj", color=True)
columna = [M*vector(x) for x in vertices]
sombra = [PR*x for x in columna]
print(max(abs(n*x) for x in sombra))                 # ≈ 0: todos los vértices de la sombra están en el plano
(plano([a, b], l=14, opacidad=0.3) + objeto(columna, caras, color=colores) + objeto(sombra, caras, color="black")).show(frame=False)

        Ejercicio 3

        Ejercicio 3 · Diagonalizar y calcular A¹⁰⁰⁰⁰

        Valores y vectores propios, P y D, y dos formas de elevar a 10000.

        3.0Qué método es más rápido

        Para cada matriz se pide: valores y vectores propios; si es diagonalizable, P y D con A = P·D·P⁻¹; y A¹⁰⁰⁰⁰ de dos formas (directamente y con la descomposición), comparando tiempos y resultados.

        • Directamente, SageMath calcula A¹⁰⁰⁰⁰ con exponenciación binaria (unas 14 elevaciones al cuadrado y pocos productos más): con matrices de enteros es exacto y muy rápido, aunque los números tengan miles de cifras.
        • Con la diagonalización, Dᵏ cuesta nada, pero hay que calcular P y P⁻¹ y trabajar con los autovalores, que pueden ser irracionales (√3 en c) o raíces de un polinomio de grado 4 (d). Su gran ventaja es teórica: da una fórmula cerrada de Aᵏ para cualquier k.
        • En coma flotante (RDF) ninguna de las dos sirve para k = 10000 si algún |λ| > 1: los números pasan de 10³⁰⁸ y salen +infinity.
        • Los tiempos son de milésimas en los dos casos y cambian de una ejecución a otra: en (a) puede ganar incluso la diagonalización, porque P y D son de enteros. Lo que cuenta es la idea: la potencia directa es exacta y general; la diagonalización da la fórmula.

        Para medir tiempos: t = walltime(); …; print(walltime(t)).

        Ejercicio 3 (a) · A = (1 2; 2 1)

        A = 1221.

        Resolución explicada

        p(λ) = (1 − λ)² − 4 = (λ − 3)(λ + 1). λ = 3 con (1, 1) y λ = −1 con (1, −1): dos autovalores distintos, diagonalizable.

        ResultadoP = 111−1, D = 300−1, A¹⁰⁰⁰⁰ = 123¹⁰⁰⁰⁰ + 13¹⁰⁰⁰⁰ − 13¹⁰⁰⁰⁰ − 13¹⁰⁰⁰⁰ + 1

        (−1)¹⁰⁰⁰⁰ = 1. 3¹⁰⁰⁰⁰ tiene 4772 cifras.

        Ejercicio 3 (a)

        A = matrix(ZZ, [[1, 2], [2, 1]])
print(A.eigenvectors_right()); D, P = A.eigenmatrix_right(); show(P, D)
t = walltime(); X = A^10000; print("directo:", walltime(t))
t = walltime(); Y = P * D^10000 * P.inverse(); print("diagonalizando:", walltime(t))
print(X == Y, len(str(X[0, 0])), X == matrix([[3^10000 + 1, 3^10000 - 1], [3^10000 - 1, 3^10000 + 1]])/2)
        Ejercicio 3 (b) · A = (1 1; 0 1)

        A = 1101.

        Resolución explicada

        p(λ) = (1 − λ)²: λ = 1 doble. A − I = 0100 tiene rango 1, así que el subespacio propio ⟨(1, 0)⟩ tiene dimensión 1 < 2: no es diagonalizable (es una cizalla).

        A¹⁰⁰⁰⁰ sólo se puede calcular directamente; por inducción Aᵏ = 1k01:

        ResultadoA¹⁰⁰⁰⁰ = 11000001

        Ejercicio 3 (b)

        A = matrix(QQ, [[1, 1], [0, 1]])                 # is_diagonalizable necesita un cuerpo (ℚ), no ℤ
print(A.eigenvectors_right(), A.is_diagonalizable()); print(A^10000)
        Ejercicio 3 (c) · una 3 × 3 con √3

        A = 31−1121−101.

        Resolución explicada

        p(λ) = −(λ³ − 6λ² + 9λ − 2) = −(λ − 2)(λ² − 4λ + 1): λ = 2 y λ = 2 ± √3. Tres autovalores distintos: diagonalizable.

        • λ = 2: (A − 2I)x = 0 da x + z = 0 y x + y − z = 0 → (1, −2, −1).
        • λ = 2 + √3: de la tercera fila x = −(1 + √3)z y de la segunda y = −z → (1 + √3, 1, −1). Para 2 − √3, el conjugado: (1 − √3, 1, −1).

        ResultadoP = 11 + √31 − √3−211−1−1−1, D = diag(2, 2 + √3, 2 − √3)

        (SageMath ordena los autovalores de otra forma y escala cada vector para que su primera coordenada sea 1: es otra P igual de válida, porque cualquier múltiplo no nulo de un vector propio lo es.)

        Para calcular exactamente con √3 sin pasar por números algebraicos generales se trabaja en el cuerpo ℚ(√3): así P·D¹⁰⁰⁰⁰·P⁻¹ es exacto y coincide con A¹⁰⁰⁰⁰ (con miles de cifras). Aun así el método directo es más rápido.

        Ejercicio 3 (c)

        A = matrix(ZZ, [[3, 1, -1], [1, 2, 1], [-1, 0, 1]])
print(A.charpoly().factor())
K.<s> = QuadraticField(3)                       # s = √3
D, P = A.change_ring(K).eigenmatrix_right(); show(P, D)
t = walltime(); X = A^10000; print("directo:", walltime(t))
t = walltime(); Y = P * D^10000 * P.inverse(); print("diagonalizando:", walltime(t))
print(X == Y, len(str(X[0, 0])))
        Ejercicio 3 (d) · una 4 × 4 sin autovalores racionales

        A = 1234211231−101101.

        Resolución explicada

        p(λ) = λ⁴ − 2λ³ − 20λ² − 2λ + 3, que es irreducible en ℚ (no tiene raíces racionales ni se parte en dos de grado 2). Tiene cuatro raíces reales distintas:

        Resultadoλ ≈ 5,6110; −3,4924; 0,3364; −0,4551 → diagonalizable (en ℝ)

        P y D sólo se pueden escribir con números algebraicos (QQbar) o aproximados (RDF). Con RDF, D¹⁰⁰⁰⁰ desborda: 5,611¹⁰⁰⁰⁰ ≈ 10⁷⁴⁹⁰ ≫ 10³⁰⁸ sale +infinity (y los |λ| < 1 dan 0), así que P·D¹⁰⁰⁰⁰·P⁻¹ no tiene sentido. La comparación de los dos métodos se ve con un exponente pequeño (A²⁰), donde el error relativo es del orden de 10⁻¹⁵; para A¹⁰⁰⁰⁰ el bueno es el directo y exacto.

        Ejercicio 3 (d)

        A = matrix(ZZ, [[1, 2, 3, 4], [2, 1, 1, 2], [3, 1, -1, 0], [1, 1, 0, 1]])
p = A.charpoly(); print(p, p.is_irreducible()); print(p.roots(RDF, multiplicities=False))
D, P = A.change_ring(RDF).eigenmatrix_right(); show(D.diagonal())
t = walltime(); X = A^10000; print("directo (exacto):", walltime(t), "cifras:", len(str(X[0, 0])))
print("|λ|^10000 en coma flotante:", [RDF(abs(l))^10000 for l in D.diagonal()])   # +infinity y 0.0: desborda
E = P * D^20 * P.inverse() - (A^20).change_ring(RDF); print("error relativo con k = 20:", E.norm() / (A^20).change_ring(RDF).norm())

        Ejercicio 6 · hachas en un madero

        Ejercicio 7 · Stonehenge

        Haz un programa que cree la escena de la imagen.

        Resolución explicada

        Todo son prismas colocados con bases adaptadas. Para cada una de las 12 posiciones Ei del círculo de radio 5: v = Ei/|Ei| (radial), u = (−v₂, v₁, 0) (tangente) y w = e₃; la piedra es un prisma que se estrecha de 1,4 × 0,5 abajo a 1,2 × 0,4 arriba. Los dinteles van de la cima de Ei a la de Ei+1 con u en la dirección Ei+1 − Ei. Los árboles son un tronco (prisma octogonal) y una copa (esfera achatada).

        Ejercicio 7

        def caja(C, u, v, w, l, g, h, l2=None, g2=None):
    l2 = l if l2 is None else l2; g2 = g if g2 is None else g2
    P0 = C + l/2*u + g/2*v; abajo = [P0, P0 - l*u, P0 - l*u - g*v, P0 - g*v]
    C1 = C + h*w; Q0 = C1 + l2/2*u + g2/2*v; arriba = [Q0, Q0 - l2*u, Q0 - l2*u - g2*v, Q0 - g2*v]
    return prisma(abajo + arriba, color=gris, opacidad=1, wire=True)
r, n, h = 5, 12, 3
E = [r*vector([cos(2*pi*i/n), sin(2*pi*i/n), 0]) for i in range(n)]
escena = prisma([2.5*x - 0.2*ejeZ3d for x in E] + [2.5*x for x in E], color=verde, opacidad=1)       # suelo
escena += caja(-2*ejeX3d, ejeX3d, ejeY3d, ejeZ3d, 1, 1.4, 0.8) + caja(-2*ejeX3d + 0.8*ejeZ3d, ejeX3d, ejeY3d, ejeZ3d, 1.3, 1.7, 0.2)  # altar
for i in range(n):
    v = E[i].normalized(); u = vector([-v[1], v[0], 0])
    escena += caja(E[i], u, v, ejeZ3d, 1.4, 0.5, h, 1.2, 0.4)                                        # piedra
    u2 = (E[(i + 1) % n] - E[i]).normalized(); v2 = vector([-u2[1], u2[0], 0])
    escena += caja((E[i] + E[(i + 1) % n])/2 + h*ejeZ3d, u2, v2, ejeZ3d, 0.95*(E[(i + 1) % n] - E[i]).norm(), 0.7, 0.8)  # dintel
for i in range(0, n, 2):
    C = 1.6*E[i]
    escena += prisma([C + 0.2*vector([cos(j*pi/4), sin(j*pi/4), 0]) for j in range(8)] + [C + 2*ejeZ3d + 0.15*vector([cos(j*pi/4), sin(j*pi/4), 0]) for j in range(8)], color='brown', opacidad=1)

        Ejercicio 8 · la columna, la columna rota y el templete

        A) Crea un programa que produzca la columna de la imagen (está hecha con 5 objetos). B) Usa un plano inclinado y la proyección oblicua para obtener la columna rota. C) Usa la columna de columna.obj, giros, traslaciones y prismas para obtener el templete.

        Resolución explicada

        A) Cinco piezas apiladas: plinto (prisma cuadrado), toro (poliedro de 16 lados que se ensancha y se estrecha), fuste estriado (prisma de 32 vértices alternando radio 0,42 y 0,37), otro toro y otro plinto arriba.

        B) Se proyecta la tapa del fuste sobre un plano inclinado de normal (1, 1, −2,3) en la dirección vertical: con Q = [u₁ v₁ e₃] (u₁, v₁ en el plano) la proyección es Q·diag(1, 1, 0)·Q⁻¹. El fuste roto es el prisma entre su base y esa tapa proyectada.

        C) Ocho columnas (la de columna.obj a escala 0,5) en un círculo de radio 5,3, giradas k·45° alrededor de Z, y prismas octogonales para el entablamento, la cubierta y los escalones.

        Ejercicio 8 (A, B)

        import warnings; warnings.filterwarnings("ignore")           # poliedro avisa de redondeos sin importancia
def anillo(C, r, n, fase=0): return [C + r*vector([cos(2*pi*i/n + fase), sin(2*pi*i/n + fase), 0]) for i in range(n)]

estrias = []
for i in range(16):

    estrias += [a, b] if i % 2 == 0 else [b, a]
fuste = estrias + [x + 4*ejeZ3d for x in estrias]

w1 = vector([1, 1, -2.3]); u1 = vector([-w1[1], w1[0], 0]); v1 = u1.cross_product(w1)

        Ejercicio 9 · una noria que gira

        A) Usa base.obj, rueda.obj y cabina.obj para generar la noria de la imagen (la rueda está centrada en el origen, tiene radio 6 y lleva 12 cabinas). B) Haz una animación para ver girar la rueda.

        Resolución explicada

        A) La rueda está en el plano XZ. La cabina i va trasladada (sin girar: las cabinas siempre cuelgan hacia abajo) al punto 6·(cos(i·30°), 0, sin(i·30°)).

        B) La rueda gira alrededor del eje Y: G = B·Rz(α)·Bᵗ con B = [e₁ e₃ e₂]. En el fotograma i se aplica Gⁱ a la rueda y las cabinas se trasladan a los puntos girados i·α. Como la rueda tiene simetría de 30°, basta animar 30° y repetir.

        Ejercicio 9

        vB, cB, colB = importarObjeto("base.obj", color=True)
vC, cC, colC = importarObjeto("cabina.obj", color=True)
vR, cR, colR = importarObjeto("rueda.obj", color=True)
base = objeto(vB, cB, color=colB)
suelo = plano([ejeX3d, ejeY3d], C=-8*ejeZ3d, color=verde, opacidad=1, l=20, g=10)
def noria(ang, rueda):
    esc = base + suelo + rueda
    for j in range(12):
        C = 6*vector([cos(ang + j*pi/6), 0, sin(ang + j*pi/6)])
        esc += objeto([C + vector(x) for x in vC], cC, color=colC)
    return esc
noria(0, objeto(vR, cR, color=colR)).show(frame=False)                               # A)
pasos = 6; a = pi/(6*pasos)
B = column_matrix([ejeX3d, ejeZ3d, ejeY3d]); G = (B*giroZ(a)*B.transpose()).change_ring(RDF)
fotogramas = [noria(i*a, objeto([G^i*vector(x) for x in vR], cR, color=colR)) for i in range(pasos)]
show(animate(fotogramas).interactive(), delay=10, auto_play=False, frame=False)     # B)
