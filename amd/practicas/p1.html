      0.1Sistemas lineales y matriz ampliada

      Un sistema de m ecuaciones con n incógnitas se escribe A·x = b, con A (m × n) la matriz de coeficientes y b la columna de términos independientes. Para resolverlo por Gauss se escalona la matriz ampliada (A | b). Hay tres posibilidades:

      • Incompatible (sin solución): la columna b es columna pivote, aparece una fila (0 ⋯ 0 | 1).
      • Compatible determinado (una solución): todas las columnas de A son pivote.
      • Compatible indeterminado (infinitas): alguna columna de A no tiene pivote; esas variables son parámetros.

      Órdenes de esta práctica

      • matrix([[fila1], [fila2], …]) y column_matrix([[col1], [col2], …]): introducir matrices por filas o por columnas. Con matrix(QQ, …) se trabaja con fracciones exactas.
      • A.augment(b, subdivide=True): la ampliada (A | b) con la barra dibujada.
      • M.rref(): la forma escalonada reducida (pivotes 1 y ceros encima y debajo). M.echelon_form() hace lo mismo sobre ℚ.
      • A*B, A+B: producto y suma. show(…): muestra bonito. load('fichero.sobj'): lee datos guardados.
      • M[:, j]: la columna j (empezando en 0) como matriz; M[[0,1,2], 3]: filas 0 a 2 de la columna 3.

      Ejercicio 2 · Estudiar y resolver sistemas

      Clasificar cada sistema con rref() y resolverlo: si es compatible determinado, comprobar la solución; si es indeterminado, dar tres soluciones y comprobarlas.

      2.0El método en SageMath

      1. Se escriben A y b (o se cargan: matricesSistemas.sobj e independientesSistemas.sobj traen los ocho sistemas en orden).
      2. Se forma la ampliada Ab = A.augment(b, subdivide=True) y se reduce: Ab.rref().
      3. Se lee el resultado: fila (0 ⋯ 0 | 1) ⇒ incompatible; pivote en cada columna de A ⇒ determinado (la última columna es la solución); si no, indeterminado.
      4. Se comprueba: A*sol == b debe dar True.

      La trampa de la última columna

      Si hay más ecuaciones que incógnitas, la última columna de la reducida tiene filas de más (los ceros de las filas nulas). Para comprobar hay que quedarse sólo con las n primeras entradas: reducida[[0,1,2], 3], no reducida[:, 3]; si no, A*sol da un error de tamaños.

      Ejercicio 2 (a) · 4 × 4, compatible determinado

      x₁ − x₂ − 5x₃ − 5x₄=6−x₁ − x₂ + 2x₃ + x₄=1−x₂ − 2x₃ − 3x₄=5x₄=−2

      Resolución explicada

      Ejercicio 2 (a)

      A = matrix([[1, -1, -5, -5], [-1, -1, 2, 1], [0, -1, -2, -3], [0, 0, 0, 1]])
b = column_matrix([6, 1, 5, -2])
Ab = A.augment(b, subdivide=True)
show("(A|b) =", Ab, "  rref =", Ab.rref())
print(A * column_matrix([0, -1, 1, -2]) == b)    # comprobación

      Las cuatro columnas de A tienen pivote y la columna b no: compatible determinado. La solución se lee en la última columna.

      Resultadox₁ = 0, x₂ = −1, x₃ = 1, x₄ = −2

      Ejercicio 3

      Ejercicio 3 · Construir sistemas

      Crear sistemas de tres ecuaciones con tres incógnitas x, y, z, con la ampliada no diagonal, que cumplan cada condición.

      Ejercicio 3 · seis sistemas a medida

      Para cada apartado, crea un sistema de 3 ecuaciones con 3 incógnitas x, y, z cuya matriz ampliada no sea diagonal: compatible determinado; incompatible; compatible indeterminado; indeterminado con todas las soluciones en función de z; en función de y; en función de y y z.

      Resolución explicada

      La idea es partir de la forma reducida que queremos y «estropearla» con operaciones de fila (que no cambian las soluciones). Los parámetros son las variables cuya columna no tiene pivote.

      • Determinado: x + y + z = 6, x − y = 0, y + z = 3 (solución única (3, 3, 0)).
      • Incompatible: x + y + z = 1, x − y = 2, 2x + z = 4 (el primer miembro de la tercera es la suma de los de las dos primeras, pero 1 + 2 = 3 ≠ 4).
      • Indeterminado: x + y + z = 1, x − y = 0, 2x + z = 1 (la tercera es la suma de las dos primeras: sobra).
      • En función de z (pivotes en x e y): x + y + 2z = 2, x − y = 0, 2x + 2y + 4z = 4 ⇒ x = y = 1 − z.
      • En función de y (pivotes en x y z): x + y + z = 1, x + y − z = 1, 2x + 2y = 2 ⇒ z = 0, x = 1 − y.
      • En función de y y z (un solo pivote, en x): x + y + z = 1, 2x + 2y + 2z = 2, −x − y − z = −1.

      Ejercicio 3: comprobación con rref

      var('x y z')
sistemas = {
  "determinado":  [x + y + z == 6, x - y == 0, y + z == 3],
  "incompatible": [x + y + z == 1, x - y == 2, 2*x + z == 4],
  "indeterminado": [x + y + z == 1, x - y == 0, 2*x + z == 1],
  "en función de z": [x + y + 2*z == 2, x - y == 0, 2*x + 2*y + 4*z == 4],
  "en función de y": [x + y + z == 1, x + y - z == 1, 2*x + 2*y == 2],
  "en función de y y z": [x + y + z == 1, 2*x + 2*y + 2*z == 2, -x - y - z == -1],
}
for nombre, ecs in sistemas.items():
    A = matrix(QQ, [[e.lhs().coefficient(v) for v in (x, y, z)] for e in ecs])
    b = column_matrix(QQ, [e.rhs() for e in ecs])
    print(nombre); print(A.augment(b, subdivide=True).rref()); print()

      En cada reducida se comprueba la condición: en «en función de z», los pivotes están en las columnas de x e y; en «en función de y», en las de x y z; en «en función de y y z», sólo en la de x.
