# UX Profile

Generated by `setup-ui-ux-skills` (VectorLab UI/UX Skills). All UI/UX work on this site reads this file before changing layout, copy, or interaction.

## Aesthetic reference

- **Standard:** Notion
- **Notes:** Web de estudio (guías, apuntes, autotests): papel tranquilo, títulos editoriales grandes, cuerpo suave, mucho aire. Profundidad por cambio de fondo y bordes finos, casi sin sombras. Un solo acento azul; el tipo de recurso (guía, chuleta, autotest, examen…) sólo se insinúa con el color de su icono pequeño, nunca con fondos o pastillas de color. Claro y oscuro con la misma lógica.

## Banned anti-aesthetics

- `backdrop-filter` / glassmorphism (barras y paneles opacos)
- Pastillas de color de fondo para metadatos estáticos (fechas, cuentas, «Teoría · Prácticas · Examen»)
- Degradados decorativos, bordes de neón, brillos exteriores
- Degradados multicolor en botones
- Ilustraciones de dibujos en estados vacíos
- Iconos decorativos dentro de los campos de texto
- Papel cuadriculado u otros fondos con dibujo
- Sombras duras (alfa ≥ 0.08 en claro) y sombras de color al pasar el ratón
- Más de un color de acento en elementos interactivos

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** texto normal ≥ 4.5:1, texto grande y bordes de controles ≥ 3:1 (comprobado para los tokens de `assets/css/base.css`)
- **Touch / focus:** objetivos táctiles de 44×44 px; anillo de foco de 2 px del color de acento con separación de 2 px

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric (en español, de tú, claro y cercano)
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** se mantiene el tono actual de la web.

## Typography

- **Familia:** Inter (400 / 500 / 600) para todo; JetBrains Mono sólo para código; Noto Sans Math de reserva para símbolos.
- **Pesos:** máximo 600. `b`/`strong` a 600.
- **Tamaños:** cuerpo 16 px, secundario 14 px, meta 12 px (mínimo). Títulos con escala Minor Third (1.2).

## Icon library

- **Library:** Project SVG
- **Package / path:** `App.icon()` en `assets/js/core.js` (trazos de 1.75–2 px, 24×24)
- **Notes:** no mezclar con otras librerías; nada de emoji como iconos de interfaz.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
