Práctica 1

Entorno de programación

En el laboratorio se arranca Ubuntu desde el menú de GRUB (usuario y contraseña alumno) y se abre Geany desde «Programación → Geany». En casa: Geany (Linux, Windows) o Dev‑C++ (Windows), que se usan casi igual. El compilador es GNU g++.

1.2Estructura de un programa C++

Igual que un algoritmo: léxico (bibliotecas con #include, tipos, constantes, variables y subprogramas globales) y algoritmo principal, que en C++ es la función main. main devuelve un int al sistema operativo: 0 = terminación normal (si no hay return, se devuelve 0). En C++ no se pueden definir funciones dentro de otras.

  • Bloque: instrucciones entre { }, cada una acabada en ;.
  • Identificadores: letras y dígitos empezando por letra (el _ cuenta como letra, pero no empieces por él). C++ distingue mayúsculas: notaFinal ≠ notafinal.
  • Palabras reservadas (no se pueden usar como nombres: using, int…), literales, operadores y delimitadores.
  • Comentarios: // hasta el final de la línea y /* varias líneas */. Los blancos y saltos de línea sólo separan.
  • using namespace std;: cin, cout y el resto de la biblioteca estándar están en el espacio de nombres std.

Reales: no compares con ==

Los cálculos con reales son aproximados. Con float, 1.0 − 0.2 − 0.8 da 0 pero 1.0 − 0.8 − 0.2 da −1.49·10−8. En vez de a == b, comprueba fabs (a − b) < EPS con una constante pequeña.

Ejercicio 1 · Intercambio circular de tres variables

Dadas A, B y C: B toma el valor de A, C el de B y A el de C. Haz una traza, piensa qué pasa si se cambia el orden de las asignaciones y codifícalo mostrando los estados intermedios.

Resolución explicada

Notación SP

Léxico
  a, b, c : Carácter;   (datos de entrada y de salida)
  aux : Carácter;       (variable auxiliar)
Algoritmo
  Leer (a, b, c);   {e1: los valores introducidos}
  aux ← b;          {e2: aux = b}
  b ← a;            {e3: b = a}
  a ← c;            {e4: a = c inicial, b = a inicial}
  c ← aux;          {e5: desplazamiento circular hecho}
  Escribir (a, b, c)
Fin

Traza con a = 'x', b = 'y', c = 'z'

Estadoabcaux
e1xyz?
e2xyzy
e3xxzy
e4zxzy
e5zxyy

¿Y si se cambia el orden? Cada asignación destruye el valor anterior de la variable. Por ejemplo, si se hace b ← a antes de aux ← b, el valor original de b se pierde y al final c recibe el de a. El orden correcto guarda primero (en aux) el valor que se va a pisar.

C++ · intercambio.cpp

#include <iostream>
using namespace std;

int main ( ) {
    char a, b, c;   // datos de entrada y de salida
    char aux;       // variable auxiliar

    cout << "Introduce tres caracteres: ";
    cin >> a >> b >> c;
    cout << "e1: a=" << a << " b=" << b << " c=" << c << endl;
    aux = b;
    cout << "e2: a=" << a << " b=" << b << " c=" << c << " aux=" << aux << endl;
    b = a;
    cout << "e3: a=" << a << " b=" << b << " c=" << c << " aux=" << aux << endl;
    a = c;
    cout << "e4: a=" << a << " b=" << b << " c=" << c << " aux=" << aux << endl;
    c = aux;
    cout << "e5: a=" << a << " b=" << b << " c=" << c << endl;
    return 0;
}

Ejecución de ejemplo

e3: a=x b=x c=z aux=y

Problema 1 · JetLag: coste de un vuelo

Por cada vuelo se anotan los kilómetros y los litros gastados; el precio del litro es propio de cada vuelo y hay un gasto fijo de mantenimiento por kilómetro. Calcula el coste total, los kilómetros por litro y el coste por kilómetro.

Resolución explicada
  • Entrada: km, litros, precioLitro, gastoKm (todos reales).
  • Salida: coste = litros · precioLitro + km · gastoKm; kmPorLitro = km / litros; costeKm = coste / km.

Notación SP

Léxico
  km, litros, precioLitro, gastoKm : Real;   // datos
  coste, kmPorLitro, costeKm : Real;         // resultados
Algoritmo
  Leer (km, litros, precioLitro, gastoKm);
  coste ← litros * precioLitro + km * gastoKm;
  kmPorLitro ← km / litros;
  costeKm ← coste / km;
  Escribir (coste, kmPorLitro, costeKm)
Fin

Traza a mano con 1200 km, 3000 l, 0.85 €/l y 1.5 €/km: coste = 2550 + 1800 = 4350 €, 0.4 km/l, 3.625 €/km.

C++ · jetlag.cpp

#include <iostream>
using namespace std;

int main ( ) {
    float km, litros, precioLitro, gastoKm;   // datos de un vuelo
    float coste, kmPorLitro, costeKm;         // resultados

    cout << "Kilómetros recorridos: ";               cin >> km;
    cout << "Litros de combustible: ";               cin >> litros;
    cout << "Precio del litro en este vuelo: ";      cin >> precioLitro;
    cout << "Gasto fijo de mantenimiento por km: ";  cin >> gastoKm;

    coste = litros * precioLitro + km * gastoKm;
    kmPorLitro = km / litros;
    costeKm = coste / km;

    cout << "Coste total del viaje: " << coste << " euros" << endl;
    cout << "Kilómetros por litro: " << kmPorLitro << endl;
    cout << "Coste por kilómetro: " << costeKm << " euros" << endl;
    return 0;
}

Problema 3 · Contenedores para cerdos ibéricos

Hay contenedores para 50, 25, 5 y 1 cerdos. Dado el número de animales, calcula cuántos contenedores de cada tipo hacen falta usando el menor número posible y, si sobra espacio, que sea el menor posible.

Resolución explicada

Es el desglose de dinero con otros «billetes». Como existe el contenedor de 1, el reparto es exacto y no sobra espacio; el método voraz (empezar por el más grande) da además el mínimo número de contenedores, porque cada tamaño es múltiplo del siguiente.

C++ · cerdos.cpp

#include <iostream>
using namespace std;

int main ( ) {
    int cerdos, resto;
    int c50, c25, c5, c1;   // contenedores de cada tamaño

    cout << "Número de cerdos: ";
    cin >> cerdos;
    c50 = cerdos / 50;  resto = cerdos % 50;
    c25 = resto / 25;   resto = resto % 25;
    c5 = resto / 5;     resto = resto % 5;
    c1 = resto;
    cout << c50 << " de 50, " << c25 << " de 25, " << c5 << " de 5 y " << c1 << " de 1" << endl;
    return 0;
}

Ejecución de ejemplo

Número de cerdos: 138
2 de 50, 1 de 25, 2 de 5 y 3 de 1

138 = 2·50 + 1·25 + 2·5 + 3·1.

Práctica 3

Análisis de casos

if, if–else y switch en C++, expresiones booleanas y problemas con análisis de casos.

3.1De SI y SEGÚN a if y switch

Notación

SI cond ENTONCES S FIN_SI
SI cond ENTONCES S SI_NO R FIN_SI
SEGÚN c1, …, cn
  e1 : S1;
  e2 : S2;
  …
  EN_OTRO_CASO : Sn+1
FIN_SEGÚN

C++

if (cond) { S }
if (cond) { S } else { R }
if (e1) { S1; }
else if (e2) { S2; }
…
else { Sn+1; }

El switch se parece al SEGÚN pero es más limitado: selecciona según el valor de una única expresión de tipo ordinal (entero, char, bool…) comparada con valores estáticos (literales o constantes conocidas al compilar). Cuando entra en un case ejecuta todo lo que encuentra hasta un break; así se asocian varios valores a un mismo tratamiento.

switch

switch (PermisoConducir) {
    case 'A':
        cout << "Motocicletas y triciclos de motor"; break;
    case 'B':
        cout << "Automóviles masa máxima autorizada <= 3500 kg"; break;
    case 'C':
        cout << "Automóviles masa máxima autorizada > 3500 kg"; break;
    default:
        cout << "No contemplado"; break;
}

Erratas del boletín

  • Los ejemplos usan comillas tipográficas (‘A’, “No contemplado") que el compilador no acepta: escribe siempre 'A' y "…" rectas.
  • En el ejemplo de if–else la rama de las mayúsculas aparece dos veces; la segunda nunca se ejecuta (casos solapados).

Problema 2 · Préstamo rápido

Un préstamo de 1 a 24 meses: interés total = cantidad · meses · interés mensual. Si el cliente tiene otras deudas se le aplica un recargo del 1 % sobre cantidad + intereses. El total se paga en cuotas mensuales iguales. Calcula la cuota.

Resolución explicada

Notación SP

Léxico
  cantidad, interes : Real;      // interés mensual en %
  meses : Entero [1, 24];

{

{

{

    cout << "Vértice B" << endl;  LeerPunto (t.b);
    cout << "Vértice C" << endl;  LeerPunto (t.c);
}

float Perimetro (Triangulo t)
{
    return Distancia (t.a, t.b) + Distancia (t.b, t.c) + Distancia (t.c, t.a);
}

Problema 4 · Rectángulos: validez y contención

Tipo Punto y tipo Rectángulo (esquina superior izquierda e inferior derecha); acción de lectura; función que diga si es válido; acción que diga si r2 está contenido en r1 y devuelva la diferencia de áreas; algoritmo principal.

Resolución explicada

Se toma el plano con el eje y hacia arriba: «por encima y a la izquierda» es supIzq.x < infDer.x y supIzq.y > infDer.y. r2 está dentro de r1 si sus dos esquinas están dentro de los límites de r1. La diferencia de áreas es el valor absoluto de la resta (área mayor − menor).

C++ · rectangulos.cpp

#include <iostream>
#include <cmath>
using namespace std;

struct Punto {
    float x, y;
};
struct Rectangulo {
    Punto supIzq, infDer;   // esquina superior izquierda e inferior derecha
};

void LeerRectangulo (Rectangulo &r)
{
    cout << "Esquina superior izquierda (x y): ";  cin >> r.supIzq.x >> r.supIzq.y;
    cout << "Esquina inferior derecha (x y): ";    cin >> r.infDer.x >> r.infDer.y;
}

/* Post: Verdadero si supIzq está por encima y a la izquierda de infDer (eje y hacia arriba) */
bool EsValido (Rectangulo r)
{
    return (r.supIzq.x < r.infDer.x) && (r.supIzq.y > r.infDer.y);
}

float Area (Rectangulo r)
{
    return (r.infDer.x - r.supIzq.x) * (r.supIzq.y - r.infDer.y);
}

/* Pre: r1 y r2 válidos
   Post: contenido = r2 está dentro de r1; difArea = área mayor − área menor */
void Relacion (Rectangulo r1, Rectangulo r2, bool &contenido, float &difArea)
{
    contenido = (r2.supIzq.x >= r1.supIzq.x) && (r2.infDer.x <= r1.infDer.x)
             && (r2.supIzq.y <= r1.supIzq.y) && (r2.infDer.y >= r1.infDer.y);
    difArea = fabs (Area (r1) - Area (r2));
}

int main ( ) {
    Rectangulo r1, r2;
    bool contenido;
    float dif;

    cout << "Rectángulo 1" << endl;  LeerRectangulo (r1);
    cout << "Rectángulo 2" << endl;  LeerRectangulo (r2);
    if (EsValido (r1)) { cout << "El rectángulo 1 es válido" << endl; }
    else { cout << "El rectángulo 1 no es válido" << endl; }
    if (EsValido (r2)) { cout << "El rectángulo 2 es válido" << endl; }
    else { cout << "El rectángulo 2 no es válido" << endl; }
    if (EsValido (r1) && EsValido (r2)) {
        Relacion (r1, r2, contenido, dif);
        if (contenido) { cout << "El segundo está contenido en el primero" << endl; }
        else { cout << "El segundo no está contenido en el primero" << endl; }
        cout << "Diferencia de áreas: " << dif << endl;
    }
    return 0;
}

Problema 5 · Circunferencias: perímetro e intersección

Tipos Punto y Circunferencia; acción de lectura; función con el perímetro (2·π·r); acción que diga si dos circunferencias intersecan; algoritmo principal.

Resolución explicada

Dos circunferencias (las curvas) tienen algún punto en común cuando la distancia d entre centros cumple |r1 − r2| ≤ d ≤ r1 + r2. Si d > r1 + r2 están separadas; si d < |r1 − r2|, una está dentro de la otra sin tocarse. (Si el enunciado se refiriera a los círculos, bastaría d ≤ r1 + r2.)

C++ · circunferencias.cpp

#include <iostream>
#include <cmath>
using namespace std;

const float PI = 3.14159;

struct Punto {
    float x, y;
};
struct Circunferencia {
    Punto centro;
    float radio;
};

void LeerCircunferencia (Circunferencia &c)
{
    cout << "Centro (x y): ";  cin >> c.centro.x >> c.centro.y;
    cout << "Radio: ";         cin >> c.radio;
}

float Perimetro (Circunferencia c)
{
    return 2 * PI * c.radio;
}

/* Post: corta = las dos circunferencias tienen algún punto en común
         ( |r1 − r2| <= d <= r1 + r2 ) */
void Intersecan (Circunferencia c1, Circunferencia c2, bool &corta)
{
    float dx, dy, d;
    dx = c1.centro.x - c2.centro.x;
    dy = c1.centro.y - c2.centro.y;
    d = sqrt (dx * dx + dy * dy);
    corta = (d <= c1.radio + c2.radio) && (d >= fabs (c1.radio - c2.radio));
}

int main ( ) {
    Circunferencia c1, c2;
    bool corta;

    cout << "Circunferencia 1" << endl;  LeerCircunferencia (c1);
    cout << "Circunferencia 2" << endl;  LeerCircunferencia (c2);
    cout << "Perímetro de la 1: " << Perimetro (c1) << endl;
    cout << "Perímetro de la 2: " << Perimetro (c2) << endl;
    Intersecan (c1, c2, corta);
    if (corta) { cout << "Las circunferencias intersecan" << endl; }
    else { cout << "Las circunferencias no intersecan" << endl; }
    return 0;
}

Problema 2 · Cociente y resto por restas sucesivas

Dados x ≥ 0 e y > 0, calcula c = x DIV y y r = x MOD y restando. Al acabar: x = y·c + r con 0 ≤ r < y. ¿Valores iniciales? ¿Actualización? ¿Condición de fin?

Resolución explicada
  • Inicial: c ← 0, r ← x (x = y·0 + x: el invariante se cumple).
  • Cuerpo: r ← r − y; c ← c + 1 (sigue cumpliéndose x = y·c + r).

#include <iostream>

    cin >> x >> y;

    r = x;
    while (r >= y) {             // Inv: x = y*c + r, r >= 0
        r = r - y;
        c = c + 1;
    }
    // r < y: x = y*c + r, 0 <= r < y
    cout << "Cociente " << c << ", resto " << r << endl;

Problema 2 · ¿Es primo? (versión mejorada)

Mejora el algoritmo de clase: los pares no son primos (salvo el 2) y basta buscar divisores hasta la raíz cuadrada.

Resolución explicada

Búsqueda del primer divisor impar d con d·d ≤ a. Si no se encuentra (d·d > a), es primo. Se compara d * d <= a para no usar reales (sqrt). El 1 no es primo y el 2 es el único par primo.

C++ · primo.cpp

#include <iostream>
using namespace std;

int main ( ) {
    int a, d;
    bool primo;

    cout << "Entero a > 0: ";
    cin >> a;
    if (a < 2) {
        primo = false;                 // 1 no es primo
    } else if (a % 2 == 0) {
        primo = (a == 2);              // el único par primo es el 2
    } else {
        d = 3;                         // sólo divisores impares hasta la raíz
        while ((d * d <= a) && (a % d != 0)) {
            d = d + 2;
        }
        primo = d * d > a;             // no se encontró divisor por debajo de la raíz
    }
    if (primo) { cout << a << " es primo" << endl; }
    else { cout << a << " no es primo" << endl; }
    return 0;

Problema 3 · Serie de ex

Suma eˣ = Σ xⁱ / i! de dos formas: (1) con funciones Factorial y Potencia; (2) calculando cada término a partir del anterior. Termina tras n términos y compara con exp.

Resolución explicada

Término siguiente a partir del actual: xⁱ⁺¹ / (i+1)! = (xⁱ / i!) · x / (i + 1): una multiplicación y una división por vuelta, frente a las i + i que hace la versión 1. Elementos del esquema: inicialización (suma ← 0, término ← 1), tratamiento (suma ← suma + término), avance (término ← término · x / (i + 1)) y parada tras n términos.

C++ · exp.cpp

#include <iostream>
#include <cmath>
using namespace std;

/* Pre: n >= 0.  Post: n! */
double Factorial (int n)
{
    double f;
    int i;
    f = 1;
    for (i = 2; i <= n; i = i + 1) {
        f = f * i;
    }
    return f;
}

/* Pre: y >= 0.  Post: x elevado a y */
double Potencia (double x, int y)
{
    double p;
    int i;
    p = 1;
    for (i = 1; i <= y; i = i + 1) {
        p = p * x;
    }
    return p;
}

int main ( ) {
    double x, suma1, suma2, termino;
    int n, i;

    cout << "x y número de términos n: ";
    cin >> x >> n;

    // Versión 1: cada término desde cero con las dos funciones
    suma1 = 0;
    for (i = 0; i < n; i = i + 1) {
        suma1 = suma1 + Potencia (x, i) / Factorial (i);
    }

    // Versión 2: cada término a partir del anterior
    termino = 1;                 // x^0 / 0!
    suma2 = 0;
    for (i = 0; i < n; i = i + 1) {
        suma2 = suma2 + termino;
        termino = termino * x / (i + 1);   // x^(i+1)/(i+1)! = x^i/i! · x/(i+1)
    }

    cout.precision(12);
    cout << "Versión 1: " << suma1 << endl;
    cout << "Versión 2: " << suma2 << endl;
    cout << "exp(x):    " << exp (x) << endl;
    return 0;
}

C++ · recurrencia.cpp

#include <iostream>
using namespace std;

int main ( ) {
    long long m, a3, a2, a1, an;   // a3 = a(n-3), a2 = a(n-2), a1 = a(n-1)
    int n, k;

    // a) menor n con a(n) > m
    cout << "m (>= 0): ";
    cin >> m;

    else if (2 > m) { n = 1; }
    else if (3 > m) { n = 2; }
    else {
        n = 2;
        an = a1;
        while (an <= m) {
            n = n + 1;
            an = 3 * a1 - 2 * a3;
            a3 = a2; a2 = a1; a1 = an;   // desplazar la «ventana» de términos
        }
    }
    cout << "a) n = " << n << endl;

    // b) término n-ésimo
    cout << "n (>= 0): ";
    cin >> k;
    a3 = 1; a2 = 2; a1 = 3;
    if (k == 0) { an = 1; }
    else if (k == 1) { an = 2; }
    else if (k == 2) { an = 3; }
    else {
        for (n = 3; n <= k; n = n + 1) {
            an = 3 * a1 - 2 * a3;
            a3 = a2; a2 = a1; a1 = an;
        }
    }
    cout << "b) a(" << k << ") = " << an << endl;
    return 0;
}

Problema 3 · Sumas de elementos adyacentes

De S = [S1, …, Sn] obtén R = [S1+S2, S2+S3, …, Sn−1+Sn]. Si S está vacía o tiene un único elemento, «La secuencia está vacía». ¿Qué tipo de problema es? ¿Qué esquema? Postcondición, invariante y diseño.

Resolución explicada
  • Tipo: recorrido (todos los pares adyacentes).
  • Esquema 3 (¬H1 y ¬H2): la vacía es un caso aparte y el primer elemento no genera salida (no tiene anterior). Aquí además hay que distinguir la secuencia de un solo elemento.
  • Post: R = SumasAdy (S). Inv: lo escrito = SumasAdy (Piz) y ant = último (Piz).

Problema 1 · Marcador de tenis

Una función que, dado el marcador y quién gana el punto, muestre el nuevo marcador; y un algoritmo que simule el partido con una secuencia de '1' y '2' terminada en '0'. Gana el partido quien llegue a seis juegos. Para «112211221»: quince–nada, treinta–nada, treinta–quince, iguales a treinta, cuarenta–treinta, juego para el jugador 1, nada–quince, nada–treinta, quince–treinta.

Resolución explicada

Como modifica el marcador, en la notación es una acción (dato–resultado marcador, dato ganador). Puntos 0, 1, 2, 3 = nada, quince, treinta, cuarenta; con 3–3 o más: «iguales a cuarenta» y «ventaja»; se gana el juego con 4 puntos o más y 2 de diferencia. El algoritmo principal es un recorrido que además para si alguien llega a seis juegos (una búsqueda).

C++ · tenis.cpp

#include <iostream>
#include <string>
using namespace std;

struct Marcador {
    int puntos1, puntos2;     // puntos del juego en curso (0, 1, 2, 3, 4…)
    int juegos1, juegos2;
};

/* Post: nombre del tanteo correspondiente a p puntos (p <= 3) */
string Nombre (int p)
{
    string s;
    switch (p) {
        case 0: s = "nada"; break;
        case 1: s = "quince"; break;
        case 2: s = "treinta"; break;
        default: s = "cuarenta"; break;
    }
    return s;
}

/* Pre: ganador es '1' o '2'
   Post: m actualizado con el punto y el nuevo marcador escrito en pantalla */
void AnotarPunto (Marcador &m, char ganador)
{
    if (ganador == '1') { m.puntos1 = m.puntos1 + 1; }
    else { m.puntos2 = m.puntos2 + 1; }

    if ((m.puntos1 >= 4) && (m.puntos1 - m.puntos2 >= 2)) {
        m.juegos1 = m.juegos1 + 1;  m.puntos1 = 0;  m.puntos2 = 0;
        cout << "juego para el jugador 1 (juegos " << m.juegos1 << "-" << m.juegos2 << ")" << endl;
    } else if ((m.puntos2 >= 4) && (m.puntos2 - m.puntos1 >= 2)) {
        m.juegos2 = m.juegos2 + 1;  m.puntos1 = 0;  m.puntos2 = 0;
        cout << "juego para el jugador 2 (juegos " << m.juegos1 << "-" << m.juegos2 << ")" << endl;
    } else if ((m.puntos1 >= 3) && (m.puntos1 == m.puntos2)) {
        cout << "iguales a cuarenta" << endl;
    } else if ((m.puntos1 >= 3) && (m.puntos2 >= 3)) {
        if (m.puntos1 > m.puntos2) { cout << "ventaja para el jugador 1" << endl; }
        else { cout << "ventaja para el jugador 2" << endl; }
    } else if (m.puntos1 == m.puntos2) {
        cout << "iguales a " << Nombre (m.puntos1) << endl;
    } else {
        cout << Nombre (m.puntos1) << "-" << Nombre (m.puntos2) << endl;
    }
}

int main ( ) {
    const char MF = '0';
    const int JUEGOS = 6;
    Marcador m;
    char EA;

    m.puntos1 = 0; m.puntos2 = 0; m.juegos1 = 0; m.juegos2 = 0;

        cin >> EA;                                                 // Avanzar
    }

    else if (m.juegos2 == JUEGOS) { cout << "Partido para el jugador 2" << endl; }
    return 0;
}
