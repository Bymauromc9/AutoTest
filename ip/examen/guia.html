1.2El método para cada problema

Las soluciones oficiales siguen siempre los mismos pasos. Hacerlos por escrito es lo que da la nota:

  1. Tipo de problema: ¿hay que mirar todos los elementos para dar la respuesta (recorrido) o se puede parar en cuanto aparezca uno (búsqueda)? Dilo con una frase: «es un recorrido porque hasta el último elemento no se sabe…».
  2. Postcondición con una función con nombre: Post ≡ { v = valorDecimal (S) }.
  3. Invariante: la post cambiando S por Piz (S), y si el tratamiento necesita el anterior, se añade u = último (Piz (S)).
  4. Definición recurrente: el caso base da la inicialización y el caso general da el tratamiento del elemento actual. valorDecimal ([]) = 0 → v ← 0; valorDecimal (T·e) = 10·valorDecimal (T) + e → v ← 10·v + EA (S).
  5. Esquema: ¿se puede tratar la secuencia vacía como las demás (H1)? ¿y el primer elemento (H2)? Si se compara con el anterior, el primero no tiene anterior: tercer esquema (¬H1, ¬H2).
  6. El algoritmo completo con su léxico, y en una búsqueda, la pregunta final de por qué se ha salido.
Si el enunciado dice…Suele serEsquema
«calcule», «cuántos», «la suma», «el número formado»RecorridoEsquema 1 (H1 y H2)
«la media», «el máximo»RecorridoEsquema 2 o 3 (la vacía o el primero aparte)
«compare con el anterior», «parejas adyacentes», «mesetas»Recorrido con el anteriorEsquema 3
«indique si existe», «el primero que», «la posición del primer»BúsquedaEsquema de búsqueda
«antes de que aparezca»Búsqueda con tratamiento de los que no cumplenBúsqueda que además cuenta
«el término n-ésimo»Recorrido de la sucesiónRECORRIENDO con dos o tres variables
«el primer término que supera»Búsqueda en la sucesiónMIENTRAS término ≤ N

Repasa los esquemas en la guía de teoría (tema 4) y velos funcionar en el simulador de la máquina secuencial.

1.3Las plantillas en C++

Recorrido (primer modelo, marca MF)

inicialización;              // solución de la secuencia vacía
cin >> EA;                   // Comenzar
while (EA != MF) {
    tratamiento de EA;
    cin >> EA;               // Avanzar
}
tratamiento final;

Búsqueda

cin >> EA;                   // Comenzar
while ((EA != MF) && !Prop (EA)) {
    cin >> EA;               // Avanzar
}
if (EA != MF) { encontrado; }
else { no hay ninguno; }

Recorrido con el anterior (tercer esquema)

cin >> EA;                   // Comenzar
if (EA == MF) { secuencia vacía; }
else {
    inicialización con el primero;
    anterior = EA;
    cin >> EA;               // Avanzar
    while (EA != MF) {
        tratamiento de anterior y EA;
        anterior = EA;
        cin >> EA;           // Avanzar
    }
}

Sucesión an = f (an-1, an-2)

ant = a1; act = a2;          // los casos base
for (i = 3; i <= n; i = i + 1) {
    sig = f (act, ant);      // INV: act = a(i-1), ant = a(i-2)
    ant = act;
    act = sig;
}
// act = an  (con n ≥ 2)

Los errores que más bajan la nota

  • Leer al principio del cuerpo del bucle en vez de al final: se trata la marca como un dato.
  • En una búsqueda, decidir el resultado mirando un contador en vez de mirar EA (o la propiedad) tras el bucle.
  • Comparar con el siguiente: siempre se razona hacia atrás, con el actual y el anterior.
  • Leer la secuencia dos veces (por ejemplo, una para contar y otra para buscar): se pide un único acceso a cada elemento.

2.1Diciembre de 2023

Diciembre 2023 · 1.A · Múltiplos, divisibles y la sucesión creativa

Ej. 1 (20 min, 4 p): S, secuencia de enteros positivos del primer modelo; calcular cuántos son múltiplos de 5. Ej. 2 (20 min, 3 p): indicar si existe algún entero divisible por 3 y por 7. Ej. 3 (30 min, 3 p): la «sucesión creativa» a1 = 3, a2 = 5, an = 2·an−1 − an−2: calcular el término M-ésimo (por ejemplo a20). En SP o en C++ con la entrada estándar y marca −1.

Resolución explicada

Explicación paso a paso

Ejercicio 1: recorrido

Hasta el último no se sabe cuántos hay: recorrido. Post: { cont = nº de múltiplos de 5 de S }. Inv: { cont = nº de múltiplos de 5 de Piz (S) }. Base: cont ← 0 (la vacía no tiene ninguno: H1). Tratamiento: si EA MOD 5 = 0, cont ← cont + 1 (H2). Esquema 1.

Ejercicio 2: búsqueda

En cuanto aparece uno la respuesta es «sí»: búsqueda con Pro (EA) ≡ (EA MOD 3 = 0) Y (EA MOD 7 = 0), que es lo mismo que EA MOD 21 = 0. Tras el bucle se mira si EA es la marca.

Ejercicio 3: sucesión

Cada término depende de los dos anteriores: hacen falta dos variables (ant y act) que se desplazan en cada vuelta. Se conoce el número de vueltas (de 3 a M): RECORRIENDO. Los primeros: 3, 5, 7, 9, 11… (es an = 2n + 1), así que a20 = 41.

Notación algorítmica

// Ejercicio 1                         // Ejercicio 2
Comenzar (S); cont ← 0;                Comenzar (S);
MIENTRAS EA (S) ≠ MarcaFin HACER       MIENTRAS (EA (S) ≠ MarcaFin) Y
  SI EA (S) MOD 5 = 0 ENTONCES             NO (EA (S) MOD 21 = 0) HACER
    cont ← cont + 1                      Avanzar (S)
  FIN_SI;                              FIN_MIENTRAS;
  Avanzar (S)                          SI EA (S) ≠ MarcaFin ENTONCES Escribir ("Sí")
FIN_MIENTRAS;                          SI_NO Escribir ("No") FIN_SI
Escribir (cont)

// Ejercicio 3 (M ≥ 2)
ant ← 3; act ← 5;
i RECORRIENDO [3, M] HACER
  sig ← 2 * act − ant; ant ← act; act ← sig      // INV: act = a(i), ant = a(i−1)
FIN_RECORRIENDO;
Escribir (act)

C++ · los tres ejercicios

#include <iostream>
using namespace std;

const int MF = -1;

// Ejercicio 1 · recorrido: cuántos son múltiplos de 5
void Ejercicio1 ( ) {
    int EA, cont;
    cont = 0;                          // solución para la secuencia vacía
    cin >> EA;                         // Comenzar
    while (EA != MF) {
        if (EA % 5 == 0) { cont = cont + 1; }
        cin >> EA;                     // Avanzar
    }
    cout << "Multiplos de 5: " << cont << endl;
}

// Ejercicio 2 · búsqueda: ¿hay alguno divisible por 3 y por 7?
void Ejercicio2 ( ) {
    int EA;
    cin >> EA;                         // Comenzar
    while ((EA != MF) && !((EA % 3 == 0) && (EA % 7 == 0))) {
        cin >> EA;                     // Avanzar
    }
    if (EA != MF) { cout << "Si: " << EA << " es divisible por 3 y por 7" << endl; }
    else { cout << "No hay ninguno divisible por 3 y por 7" << endl; }
}

// Ejercicio 3 · sucesión: a1 = 3, a2 = 5, an = 2·an-1 − an-2; término M-ésimo (M ≥ 1)
int Termino (int M) {
    int ant, act, sig, i;
    if (M == 1) { return 3; }
    ant = 3; act = 5;                  // a1 y a2
    for (i = 3; i <= M; i = i + 1) {   // INV: act = a(i-1), ant = a(i-2)
        sig = 2 * act - ant;
        ant = act;
        act = sig;
    }
    return act;
}

int main ( ) {
    int M;
    cout << "Enteros positivos, para terminar -1" << endl;
    Ejercicio1 ( );
    cout << "Enteros positivos, para terminar -1" << endl;
    Ejercicio2 ( );
    cout << "M: ";
    cin >> M;
    cout << "a" << M << " = " << Termino (M) << endl;
    return 0;
}

Diciembre 2023 · 1.B · La otra versión del examen

Igual que el 1.A cambiando: Ej. 1, contar los divisibles por 7; Ej. 2, ¿existe alguno múltiplo de 2 y de 3?; Ej. 3, el primer término de la sucesión creativa que supera un valor M dado (para M = 100 es a50 = 101).

Resolución explicada

Explicación paso a paso

Los ejercicios 1 y 2 son los del 1.A cambiando la propiedad: EA MOD 7 = 0 y EA MOD 6 = 0. El 3 cambia de tipo: ya no se sabe cuántos términos hay que generar, así que es una búsqueda en la sucesión: se generan términos mientras no superen M, llevando la cuenta del índice n.

Ejercicio 3 en notación algorítmica

ant ← 3; act ← 5; n ← 2;
SI ant > M ENTONCES act ← ant; n ← 1          // a1 ya supera M
SI_NO
  MIENTRAS act ≤ M HACER                      // INV: act = a(n), ant = a(n−1), a(1..n−1) ≤ M
    sig ← 2 * act − ant; ant ← act; act ← sig; n ← n + 1
  FIN_MIENTRAS
FIN_SI;
Escribir ("a", n, " = ", act)

C++ · ejercicio 3

#include <iostream>
using namespace std;

// Examen 1.B · ejercicio 3: primer término de la sucesión creativa que supera M
int main ( ) {
    int M, ant, act, sig, n;
    cout << "M: ";
    cin >> M;
    ant = 3; act = 5; n = 2;           // a1 y a2
    if (ant > M) {
        act = ant; n = 1;              // ya lo supera a1
    } else {
        while (act <= M) {             // búsqueda: se para en el primero que supera M
            sig = 2 * act - ant;
            ant = act;
            act = sig;
            n = n + 1;
        }
    }
    cout << "El primero que supera " << M << " es a" << n << " = " << act << endl;
    return 0;
}

El primero que supera 100 es a50 = 101

2.2Diciembre de 2022

Diciembre 2022 · A · Saldo de una cuenta y un producto financiero

S es una secuencia (primer modelo) con los ingresos y reintegros de una cuenta. 1a (4 p): calcular el saldo disponible (1100, 3300, −300, 400 → 4500 €). 1b (3 p): indicar si la cuenta ha estado en números rojos en algún momento (1100, 3300, −5000, 4000 → saldo de −600 € tras la tercera operación). 2 (3 p): un producto dobla cada 1 de enero el capital y cobra 200 € de comisión: a0 = M (1-1-2022), an = 2·an−1 − 200. ¿Cuánto habrá el 1 de enero del año A?

Resolución explicada

Explicación paso a paso

1a: recorrido

El saldo es la suma de todas las operaciones: Inv { saldo = Σ Piz (S) }, saldo ← 0, saldo ← saldo + EA (S). Esquema 1.

1b: búsqueda

«Si en algún momento» → en cuanto el saldo sea negativo ya se sabe: búsqueda. Pero la propiedad no es del elemento solo, sino del saldo acumulado: se mantiene saldo = Σ Piz (S) y Pro ≡ saldo + EA (S) < 0. Al salir, si EA no es la marca, el saldo negativo es saldo + EA.

2: recorrido de la sucesión

Del 2022 al año A hay A − 2022 pasos, un número conocido: RECORRIENDO con una sola variable, porque cada término sólo depende del anterior. Con M = 1000: 1800, 3400, 6600 y 13000 € en 2026.

Notación algorítmica

// 1b
Comenzar (S); saldo ← 0;
MIENTRAS (EA (S) ≠ MarcaFin) Y (saldo + EA (S) ≥ 0) HACER
  saldo ← saldo + EA (S);                 // INV: saldo = Σ Piz (S) ≥ 0 en todo momento
  Avanzar (S)
FIN_MIENTRAS;
SI EA (S) ≠ MarcaFin ENTONCES Escribir ("Números rojos: ", saldo + EA (S))
SI_NO Escribir ("Nunca ha estado en números rojos")
FIN_SI

// 2
a ← M;
año RECORRIENDO [2023, A] HACER a ← 2 * a − 200 FIN_RECORRIENDO;
Escribir (a)

En C++ hace falta una marca que no pueda ser una operación: aquí 0 (nadie ingresa 0 €).

C++ · 1a, 1b y 2

#include <iostream>
using namespace std;

const int MF = 0;                      // marca: una operación de 0 euros no existe

// 1a · recorrido: saldo final = suma de todas las operaciones
void Saldo ( ) {
    int EA, saldo;
    saldo = 0;
    cin >> EA;                         // Comenzar
    while (EA != MF) {
        saldo = saldo + EA;            // INV: saldo = suma de Piz
        cin >> EA;                     // Avanzar
    }
    cout << "Saldo disponible: " << saldo << " euros" << endl;
}

// 1b · búsqueda: ¿algún saldo parcial negativo?
void NumerosRojos ( ) {
    int EA, saldo, n;
    saldo = 0; n = 0;
    cin >> EA;                         // Comenzar
    while ((EA != MF) && (saldo + EA >= 0)) {
        saldo = saldo + EA;
        n = n + 1;
        cin >> EA;                     // Avanzar
    }
    if (EA != MF) {
        cout << "Numeros rojos: saldo de " << saldo + EA << " euros tras la operacion " << n + 1 << endl;
    } else {
        cout << "La cuenta nunca ha estado en numeros rojos" << endl;
    }
}

// 2 · sucesión: a0 = M (1 de enero de 2022), an = 2·an-1 − 200; saldo el 1 de enero del año A
int SaldoEnAnyo (int M, int A) {
    int a, anyo;
    a = M;
    for (anyo = 2023; anyo <= A; anyo = anyo + 1) {
        a = 2 * a - 200;
    }
    return a;
}

int main ( ) {
    cout << "Operaciones (0 para terminar):" << endl;
    Saldo ( );
    cout << "Operaciones (0 para terminar):" << endl;
    NumerosRojos ( );
    cout << "M = 1000, A = 2026: " << SaldoEnAnyo (1000, 2026) << " euros" << endl;
    return 0;
}

Diciembre 2022 · B · Divisibilidad por 3 y el año del coche

S es una secuencia con las cifras de un número (1, 2, 4, 5 → 1245). 1a (4 p): indicar si el número es divisible por 3 usando que lo es si la suma de sus cifras lo es. 1b (3 p): indicar si contiene alguna cifra par. 2 (3 p): con el producto del examen A (a0 = M, an = 2·an−1 − 200), ¿en qué año habrá suficiente para un coche de 30000 €?

Resolución explicada

Explicación paso a paso

1a: recorrido

Hay que sumar todas las cifras: recorrido con suma ← 0 y suma ← suma + EA (S). La pregunta (suma MOD 3 = 0) se hace en el tratamiento final. 1 + 2 + 4 + 5 = 12 → sí.

1b: búsqueda

Pro (EA) ≡ EA MOD 2 = 0. En 1245 se para en el 2.

2: búsqueda en la sucesión

Ahora no se sabe cuántos años: se busca el primero con a ≥ 30000. Ojo: si M ≤ 200 el saldo nunca crece (con 200 se queda igual y con menos baja) y el bucle no terminaría: hay que suponer M > 200 o comprobarlo antes. Con M = 1000: 1800, 3400, 6600, 13000, 25800, 51400 → 2028.

Ejercicio 2 en notación algorítmica

// PRE: M > 200
a ← M; año ← 2022;
MIENTRAS a < 30000 HACER        // INV: a = saldo el 1 de enero de año
  a ← 2 * a − 200;
  año ← año + 1
FIN_MIENTRAS;
Escribir (año)

C++ · 1a, 1b y 2

#include <iostream>
using namespace std;

const int MF = -1;

// 1a · recorrido: suma de las cifras y, al final, ¿es divisible por 3?
void DivisiblePor3 ( ) {
    int EA, suma;
    suma = 0;
    cin >> EA;                         // Comenzar
    while (EA != MF) {
        suma = suma + EA;
        cin >> EA;                     // Avanzar
    }
    if (suma % 3 == 0) { cout << "Divisible por 3 (suma de cifras " << suma << ")" << endl; }
    else { cout << "No es divisible por 3 (suma de cifras " << suma << ")" << endl; }
}

// 1b · búsqueda: ¿alguna cifra par?
void CifraPar ( ) {
    int EA;
    cin >> EA;                         // Comenzar
    while ((EA != MF) && (EA % 2 != 0)) {
        cin >> EA;                     // Avanzar
    }
    if (EA != MF) { cout << "Contiene la cifra par " << EA << endl; }
    else { cout << "No contiene ninguna cifra par" << endl; }
}

// 2 · búsqueda en una sucesión: año en que el saldo llega a 30000 (necesita M > 200)
int AnyoCoche (int M) {
    int a, anyo;
    a = M; anyo = 2022;
    while (a < 30000) {
        a = 2 * a - 200;
        anyo = anyo + 1;
    }
    return anyo;
}

int main ( ) {
    cout << "Cifras del numero, para terminar -1" << endl;
    DivisiblePor3 ( );
    cout << "Cifras del numero, para terminar -1" << endl;
    CifraPar ( );
    cout << "Con M = 1000 euros el coche se compra en " << AnyoCoche (1000) << endl;
    return 0;
}

3.1Parcial de noviembre de 2019

Noviembre 2019 · Número decimal, dobles del anterior y vocal débil

1 (4 p): S (primer modelo) contiene las cifras de un número; obtener el número accediendo una vez a cada elemento ([4, 5, 6, 4, 5] → 45645; vacía → 0). 2 (2,5 p): S del segundo modelo; contar los elementos que son el doble del anterior ([1, 2, 4, 5, 5, 7, 44, 22, 3, 6] → 3). 3 (3,5 p): función VocalDébil (S) que diga si un texto del primer modelo contiene alguna i o u.

Resolución explicada

Explicación paso a paso

1: recorrido (solución oficial)

Añadir una cifra por la derecha es multiplicar por 10 y sumarla: valorDecimal ([]) = 0, valorDecimal (T·e) = 10·valorDecimal (T) + e. La vacía vale 0 y el primero se trata igual (10·0 + e = e): esquema 1.

2: recorrido con el anterior

Cada elemento se compara con el anterior: el invariante lleva u = último (Piz (S)) y el primero no tiene anterior: tercer esquema. Con el segundo modelo: Iniciar, y si no es vacía, Avanzar para tener el primero, u ← EA; luego MIENTRAS NO EsÚltimo, Avanzar y comparar.

3: búsqueda

En cuanto aparece una i o una u la respuesta es sí. Pro (EA) ≡ EA = 'u' O EA = 'i'; por De Morgan, NO Pro ≡ EA ≠ 'u' Y EA ≠ 'i'. Se usa YDESPUÉS para no mirar la marca.

2 · segundo modelo (oficial)

Iniciar (S);
SEGÚN EsVacía (S)
  EsVacía (S) : Escribir (0);
  NO EsVacía (S) :
    Avanzar (S);
    r ← 0; u ← EA (S);
    MIENTRAS NO EsÚltimo (S) HACER
      Avanzar (S);
      SI EA (S) = 2 * u ENTONCES r ← r + 1 FIN_SI;
      u ← EA (S)
    FIN_MIENTRAS;
    Escribir (r)
FIN_SEGÚN

3 · función de búsqueda (oficial)

VocalDébil : función (S : Secuencia de Carácter)
             → Booleano;
ALGORITMO
  Comenzar (S);
  MIENTRAS EA (S) ≠ MarcaFin YDESPUÉS
           (EA (S) ≠ 'u' Y EA (S) ≠ 'i') HACER
    Avanzar (S)
  FIN_MIENTRAS;
  VocalDébil ← EA (S) ≠ MarcaFin
FIN;

Con «No sé cómo resolverlo», «» o « » devuelve falso; con «El problema es sencillo», verdadero (la i de sencillo). En C++ la secuencia del 2 se lee con marca, que es el primer modelo.

C++ · los tres ejercicios

#include <iostream>
using namespace std;

const int MF = -1;
const char MFC = '#';

// 1 · recorrido: el número formado por las cifras (valorDecimal (T·e) = 10·valorDecimal (T) + e)
void Numero ( ) {
    int EA, v;
    v = 0;                             // valorDecimal ([]) = 0
    cin >> EA;                         // Comenzar
    while (EA != MF) {
        v = 10 * v + EA;
        cin >> EA;                     // Avanzar
    }
    cout << "Numero: " << v << endl;
}

// 2 · recorrido con el anterior (¬H1, ¬H2): parejas en las que el segundo es el doble del primero
void Dobles ( ) {
    int EA, u, r;
    cin >> EA;                         // Comenzar
    if (EA == MF) {
        cout << "Parejas: 0" << endl;
    } else {
        r = 0;
        u = EA;                        // u = último de Piz

Junio 2017 · Mesetas y una sucesión con tres términos

1: S (primer modelo) de enteros; obtener una secuencia T con un único elemento de cada meseta (31 31 31 45 22 22 33 15 15 15 15 → 31 45 22 33 15). 2: a0 = a1 = 1, ai = 7·ai−1 − ai−2 − 2; calcular el menor i > 1 tal que ai > N (N > 0).

Resolución explicada

Explicación paso a paso

1: recorrido con el anterior

Un elemento empieza meseta si es distinto del anterior: tercer esquema. El primero siempre se registra. Inv { T = EliminarRepetidos (Piz (S)) Y anterior = último (Piz (S)) }.

Cada término depende de dos anteriores: tres variables (aant, anterior, actual). a2 = 4, a3 = 25, a4 = 169… Se generan mientras actual ≤ N. Para N = 100: i = 4.

1 · solución oficial (con ITERAR)

        i = i + 1;

    return i;

Junio 2025 · La ocupación de un hotel

Un hotel de M habitaciones. Una secuencia marcada con −1 (de la entrada estándar) da cuántas hay ocupadas cada día, empezando en lunes. 3a: escribir el promedio de ocupación (%) de cada semana completa. 3b: acción LlenoVacio que devuelva en Existe 0 (ni día lleno ni vacío), 1 (algún día lleno), 2 (algún día vacío) o 3 (las dos cosas), con el menor número de accesos a la secuencia.

Resolución explicada

Explicación paso a paso

3a: recorrido por bloques

Se recorren los días contando dia de 1 a 7 y sumando; al llegar a 7 se escribe la semana y se reinicia. Lo que quede al final (semana incompleta) no se escribe. Promedio = 100 · suma / (7 · M), con la división real.

3b: búsqueda

«El menor número de accesos» es la pista: en cuanto se han visto un día lleno y uno vacío ya no hace falta leer más. Es una búsqueda cuya propiedad es Existe = 3. Usar 1 y 2 como «banderas» y sumarlas es un truco elegante: la suma da directamente el código pedido.

  • La solución oficial usa un switch para distinguir M y 0; con if … else if queda igual.

C++ · solución oficial (ordenada)

#include <iostream>
using namespace std;

const int M = 30;                      // habitaciones del hotel (por ejemplo)
const int DIAS_SEMANA = 7;
const int MARCA_FIN = -1;
const int HAY_DIA_LLENO = 1;
const int HAY_DIA_VACIO = 2;
const int HAY_DIAS_DE_TODO = HAY_DIA_LLENO + HAY_DIA_VACIO;

// 3a · recorrido: promedio de ocupación de cada semana completa
void Ocupacion ( ) {
    int semana, dia, suma, EA;
    float promedio;
    semana = 0; dia = 0; suma = 0;
    cin >> EA;                         // Comenzar
    while (EA != MARCA_FIN) {
        dia = dia + 1;
        suma = suma + EA;
        if (dia == DIAS_SEMANA) {      // se cierra una semana
            promedio = 100.0 * suma / (DIAS_SEMANA * M);
            semana = semana + 1;
            cout << "Semana " << semana << ": " << promedio << "%" << endl;
            dia = 0;
            suma = 0;
        }
        cin >> EA;                     // Avanzar
    }                                  // una semana incompleta no se escribe
}

// 3b · búsqueda: se para en cuanto se han visto un día lleno y uno vacío
void LlenoVacio (int &Existe) {
    int EA, diaLleno, diaVacio;
    diaLleno = 0; diaVacio = 0;
    Existe = 0;
    cin >> EA;                         // Comenzar
    while ((EA != MARCA_FIN) && (Existe != HAY_DIAS_DE_TODO)) {
        if (EA == M) { diaLleno = HAY_DIA_LLENO; }
        else if (EA == 0) { diaVacio = HAY_DIA_VACIO; }
        Existe = diaLleno + diaVacio;
        cin >> EA;                     // Avanzar
    }
}

int main ( ) {
    int existe;
    cout << "Ocupacion diaria (M = 30), para terminar -1" << endl;
    Ocupacion ( );
    cout << "Ocupacion diaria (M = 30), para terminar -1" << endl;
    LlenoVacio (existe);
    cout << "Existe = " << existe << endl;
    return 0;
}

Problemas de secuencias

La hoja de problemas de secuencias de clase: diptongos, búsquedas con tratamiento, parejas adyacentes y el descenso más largo.

4.1Los cinco problemas

Problema 1 · Diptongos crecientes y decrecientes

Contar los diptongos crecientes (i/u seguida de a/e/o) y decrecientes (a/e/o seguida de i/u) de un texto. «El restaurante La aceituna pasó la prueba del aislante de sonido» → 3 decrecientes y 1 creciente.

Resolución explicada

Explicación paso a paso

Un diptongo es una pareja actual–anterior: recorrido con el tercer esquema (el primero no tiene anterior). En cada paso se mira si (anterior, EA) es creciente o decreciente. Decrecientes: au (restaurante), ei (aceituna), ai (aislante); creciente: ue (prueba). Las vocales con tilde no cuentan (ó ≠ o).

  • Siempre se compara el actual con el anterior, nunca con el siguiente.

C++

#include <iostream>
using namespace std;

const char MF = '#';

bool Abierta (char c) { return (c == 'a') || (c == 'e') || (c == 'o'); }
bool Cerrada (char c) { return (c == 'i') || (c == 'u'); }

// Problema 1 · recorrido con el anterior (tercer esquema): diptongos crecientes y decrecientes
int main ( ) {
    char EA, anterior;
    int crecientes, decrecientes;
    cout << "Frase terminada en #:" << endl;
    cin.get (EA);                      // Comenzar
    if (EA == MF) {
        cout << "La secuencia esta vacia" << endl;
    } else {
        crecientes = 0; decrecientes = 0;
        anterior = EA;                 // el primero no forma pareja con nadie
        cin.get (EA);                  // Avanzar
        while (EA != MF) {
            if (Cerrada (anterior) && Abierta (EA)) { crecientes = crecientes + 1; }
            else if (Abierta (anterior) && Cerrada (EA)) { decrecientes = decrecientes + 1; }
            anterior = EA;
            cin.get (EA);              // Avanzar
        }
        cout << "Decrecientes: " << decrecientes << "  Crecientes: " << crecientes << endl;
    }
    return 0;
}

Problema 2 · El primer diptongo creciente y su posición

Indicar si hay algún diptongo creciente y, si lo hay, la posición de su primera letra. «La prueba del polígrafo» → posición 6; «Esto no es una pipa» → no contiene ninguno.

Resolución explicada

Explicación paso a paso

Ahora basta con el primero: búsqueda con el anterior. Pro ≡ DiptongoCreciente (anterior, EA). Se lleva la posición del elemento actual; la primera letra del diptongo es la anterior, así que se escribe pos − 1. En «La prueba»: L1 a2 ␣3 p4 r5 u6 e7.

  • Escribir la condición con una función booleana la hace más legible (y no cuesta nada).

C++

#include <iostream>
using namespace std;

const char MF = '#';

bool DiptongoCreciente (char primero, char segundo) {
    return ((primero == 'i') || (primero == 'u')) &&
           ((segundo == 'a') || (segundo == 'e') || (segundo == 'o'));
}

// Problema 2 · búsqueda con el anterior: posición del primer diptongo creciente
int main ( ) {
    char EA, anterior;
    int pos;                           // posición de EA en la secuencia
    cout << "Frase terminada en #:" << endl;
    cin.get (EA);                      // Comenzar

        anterior = EA; pos = 1;
        cin.get (EA); pos = pos + 1;   // Avanzar
        while ((EA != MF) && !DiptongoCreciente (anterior, EA)) {
            anterior = EA;
            cin.get (EA); pos = pos + 1;
        }
        if (EA != MF) { cout << "Contiene un diptongo en la posicion " << pos - 1 << endl; }
        else { cout << "No contiene ningun diptongo" << endl; }
    }

}

Problema 3 · Divisibles por 3 antes del primer impar

En una secuencia de enteros positivos, contar los divisibles por 3 que hay antes del primer impar. Si hay impar, escribir el impar, su posición y la cuenta; si no, que no existe y la cuenta. 2 3 2 5 → valor 3, posición 2, divisibles 0; 6 12 4 → no existe impar, divisibles 2.

Resolución explicada

Explicación paso a paso

Es una búsqueda (del primer impar) que además trata los elementos que no cumplen (los pares de delante): dentro del bucle se cuentan los divisibles por 3. Tras el bucle, si EA no es la marca, EA es el impar. El impar no se cuenta aunque sea divisible por 3 (el 3 del primer ejemplo).

  • Es el patrón «búsqueda + recorrido de la parte izquierda»: el contador sólo mira Piz.

#include <iostream>

const int MF = -1;

// Problema 3 · búsqueda del primer impar contando, mientras tanto, los divisibles por 3
int main ( ) {
    int EA, pos, divisibles;
    cout << "Enteros positivos, para terminar -1" << endl;
    divisibles = 0; pos = 1;

    } else {

    }

Problema 4 · Suma de las parejas par–impar

Sumar las parejas adyacentes en las que el primero es par y el segundo impar. La suma de la vacía no está definida. 2 2 2 2 3 4 4 5 6 → 14 (2+3 y 4+5); 5 5 3 3 4 6 → 0.

Resolución explicada

Explicación paso a paso

Recorrido con el anterior: tercer esquema. La vacía se trata aparte porque su suma no está definida (¬H1); con un único elemento la suma es 0. Tratamiento: si anterior es par y EA impar, suma ← suma + anterior + EA.

  • En C++, «impar» es EA % 2 != 0.

#include <iostream>

const int MF = -1;

// Problema 4 · recorrido con el anterior: suma de las parejas adyacentes (par, impar)

    } else {
        suma = 0;
        anterior = EA;
        cin >> EA;                     // Avanzar
        while (EA != MF) {
            if ((anterior % 2 == 0) && (EA % 2 != 0)) { suma = suma + anterior + EA; }
            anterior = EA;
            cin >> EA;                 // Avanzar
        }
        cout << "Salida: " << suma << endl;
    }
    return 0;
}

Problema 5 · El periodo más largo de descenso

Una secuencia con los positivos diarios de PCR desde el 1 de enero. Indicar el periodo más largo de descenso (Si ≤ Si−1), el día en que empezó y el día en que terminó. Con el ejemplo del enunciado: 6 días, del 8 al 13.

Resolución explicada

Explicación paso a paso

Es el problema de la meseta más larga cambiando «igual» por «menor o igual». El invariante necesita cuatro cosas de Piz: anterior (el último), longActual (lo que mide el descenso que acaba en el último), longMayor y posFinMayor (el más largo hasta ahora y dónde acaba), y la posición del EA. Si EA ≤ anterior, el descenso crece y quizá supera al mayor; si no, empieza uno nuevo de longitud 1. El inicio es posFinMayor − longMayor + 1.

  • Se actualiza el mayor dentro del bucle, cada vez que el actual lo supera: así el último tramo no se queda sin comparar.

C++ (la solución del profesorado, ordenada)

#include <iostream>
using namespace std;

const int MF = -100;

// Problema 5 · recorrido con el anterior: el periodo de descenso (Si <= Si-1) más largo
int main ( ) {
    int EA, anterior, posEA, longActual, longMayor, posFinMayor;
    cout << "Positivos diarios, para terminar -100" << endl;
    cin >> EA;                         // Comenzar
    if (EA == MF) {
        cout << "Secuencia vacia" << endl;
    } else {
        longActual = 1; longMayor = 1; posFinMayor = 1;
        anterior = EA; posEA = 2;
        cin >> EA;                     // Avanzar
        while (EA != MF) {
            if (EA <= anterior) {      // el descenso continúa
                longActual = longActual + 1;
                if (longActual > longMayor) { longMayor = longActual; posFinMayor = posEA; }
            } else {
                longActual = 1;        // empieza un tramo nuevo en EA
            }
            anterior = EA;
            posEA = posEA + 1;
            cin >> EA;                 // Avanzar
        }
        cout << "El periodo mas largo de descenso es de " << longMayor << " dias, comienza el dia "
             << posFinMayor - longMayor + 1 << " y termina el dia " << posFinMayor << endl;
    }
    return 0;
}

5.1Las dos versiones

Tipo A · Reservas de una sala

Una hora es (h, m) y una reserva, una hora de inicio y otra de fin en el mismo día (minutos = 60·h + m). 1 (1 p) Tipos Hora y Reserva. 2 (2 p) Acción que lea una reserva (sólo escalares) y la devuelva. 3 (2,5 p) Función que diga si es válida: horas en [0, 23], minutos en [0, 59] e inicio estrictamente anterior al fin. 4 (2,5 p) Acción que devuelva la diferencia en minutos entre la duración mayor y la menor de dos reservas. 5 (2 p) Algoritmo que lea dos reservas y, si son válidas, escriba la diferencia.

Resolución explicada

Explicación paso a paso

  1. Registros anidados: Hora = TIPO <h, m : Entero> y Reserva = TIPO <ini, fin : Hora>.
  2. La acción tiene un parámetro resultado y lee campo a campo (Leer (r.ini.h, r.ini.m)): no se puede leer un registro entero.
  3. Una función auxiliar Minutos (t) = 60·t.h + t.m simplifica todo: «inicio antes que fin» es Minutos (ini) < Minutos (fin).
  4. Diferencia = |d1 − d2| con un SI (no hay valor absoluto en la notación).
  5. El algoritmo sólo combina lo anterior.

Erratas de la solución publicada

  • 0 ≤ r.hora_i.h ≤ 23 encadenado no es válido ni en la notación ni en C++: hay que escribir (0 ≤ h) Y (h ≤ 23).
  • Faltan los FIN_SI y hay erratas de nombres (Leer_Reseva, resserva2).

C++

#include <iostream>
using namespace std;

// Apartado 1: tipos
struct Hora {
    int h;
    int m;
};
struct Reserva {
    Hora ini;
    Hora fin;
};

// Apartado 2: acción con parámetro resultado (sólo se leen escalares)
void LeerReserva (Reserva &r) {
    cout << "Hora y minutos de inicio: ";
    cin >> r.ini.h >> r.ini.m;
    cout << "Hora y minutos de fin: ";
    cin >> r.fin.h >> r.fin.m;
}

int Minutos (Hora t) {                 // función auxiliar: minutos desde las 00:00
    return 60 * t.h + t.m;
}

bool HoraValida (Hora t) {
    return (t.h >= 0) && (t.h <= 23) && (t.m >= 0) && (t.m <= 59);
}

// Apartado 3
bool ReservaValida (Reserva r) {
    return HoraValida (r.ini) && HoraValida (r.fin) && (Minutos (r.ini) < Minutos (r.fin));
}

// Apartado 4: dif = duración mayor − duración menor
void Diferencia (Reserva r1, Reserva r2, int &dif) {
    int d1, d2;
    d1 = Minutos (r1.fin) - Minutos (r1.ini);
    d2 = Minutos (r2.fin) - Minutos (r2.ini);
    if (d1 < d2) { dif = d2 - d1; }
    else { dif = d1 - d2; }
}

// Apartado 5
int main ( ) {
    Reserva r1, r2;
    int dif;
    cout << "Reserva 1" << endl;
    LeerReserva (r1);
    cout << "Reserva 2" << endl;
    LeerReserva (r2);
    if (ReservaValida (r1) && ReservaValida (r2)) {
        Diferencia (r1, r2, dif);
        cout << "La diferencia es de " << dif << " minutos" << endl;
    } else {
        cout << "Alguna de las reservas no es valida" << endl;
    }
    return 0;
}

Tipo B · Tramos de una carretera

Lo mismo con posiciones (km, m) en una carretera de 500 km (distancia = 1000·km + m). Un tramo es válido si sus dos posiciones lo son (km en [0, 500] y m en [0, 999], y si km = 500, m = 0) y la inicial está estrictamente antes que la final. La acción devuelve la diferencia en metros entre la longitud mayor y la menor.

Resolución explicada

Explicación paso a paso

Es el tipo A con otros nombres. La condición de posición válida tiene dos casos: (0 ≤ km < 500 Y 0 ≤ m ≤ 999) O (km = 500 Y m = 0). Con una función auxiliar Metros (p) la comparación y las longitudes son inmediatas (la solución oficial lo sugiere como «versión mejorada»).

Erratas de la solución publicada

  • Escribe trm.pIni.mn en lugar de trm.pIni.m.
  • El C++ tiene guiones largos (–) en las restas y comillas tipográficas en el último cout: tal cual no compila.

C++ (la oficial, corregida y con funciones auxiliares)

#include <iostream>
using namespace std;

// Apartado 1
struct Posicion {
    int km;
    int m;
};
struct Tramo {
    Posicion pIni;
    Posicion pFin;
};

// Apartado 2
void LeerTramo (Tramo &trm) {
    cout << "Posicion inicial (km y m): ";
    cin >> trm.pIni.km >> trm.pIni.m;
    cout << "Posicion final (km y m): ";
    cin >> trm.pFin.km >> trm.pFin.m;
}

int Metros (Posicion p) {              // distancia desde el inicio de la carretera
    return 1000 * p.km + p.m;
}

bool PosicionValida (Posicion p) {
    return ((p.km >= 0) && (p.km < 500) && (p.m >= 0) && (p.m <= 999))
           || ((p.km == 500) && (p.m == 0));
}

// Apartado 3
bool TramoValido (Tramo trm) {
    return PosicionValida (trm.pIni) && PosicionValida (trm.pFin)
           && (Metros (trm.pIni) < Metros (trm.pFin));
}

// Apartado 4
void DifTramo (Tramo t1, Tramo t2, int &difer) {

    long2 = Metros (t2.pFin) - Metros (t2.pIni);
    if (long1 >= long2) { difer = long1 - long2; }
    else { difer = long2 - long1; }
}
